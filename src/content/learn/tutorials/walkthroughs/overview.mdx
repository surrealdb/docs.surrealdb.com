# Tutorials

This section holds **tutorials**: practical **walkthroughs** that take you through a task or feature in order, with commands, configuration, and code you can follow along with. They are aimed at learning and production-style setup rather than only skimming a finished app.

If you prefer a **ready-made project** you can clone and run with minimal narrative, see the [demos](/docs/learn/tutorials/demos/overview) section instead.

If you are new to SurrealDB, you may also want [Getting started](/docs) and the [SurrealQL](/docs/reference/query-language) reference.

## Getting started

- [Define a schema in SurrealDB](/docs/learn/tutorials/walkthroughs/define-a-schema) - build up a schemafull table with fields, assertions and indexes
- [Query SurrealDB from Postman](/docs/learn/tutorials/walkthroughs/http-via-postman) - drive the HTTP endpoints from a REST client
- [Connect to SurrealDB via ngrok](/docs/learn/tutorials/walkthroughs/connect-via-ngrok) - expose a local instance to a remote client
- [Use SurrealDB in GitHub Actions](/docs/learn/tutorials/walkthroughs/github-actions) - run a database alongside your CI jobs

## Authentication

- [Integrate an identity provider with SurrealDB](/docs/learn/tutorials/walkthroughs/identity-provider-integration) - verify tokens from Auth0, AWS Cognito or Authorizer with a record access method
