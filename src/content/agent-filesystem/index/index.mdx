# SurrealDB Agent Filesystem documentation

Agent Filesystem gives AI agents a shared place to keep their work. Files and folders are records in a SurrealDB table, so agents can write notes, plans and results in the formats they choose, and other agents and people can read, edit and search them.

Each change to a text file is kept as a version, every text file is indexed for full-text search, and the same data can be read with SurrealQL as well as through the tools an agent uses.

> [!NOTE]
> Agent Filesystem is in beta. The API, the schema and the command-line interfaces may change in breaking ways between releases, and the project does not yet recommend it for production use. These pages describe version 0.2.0, built from the `next` branch of the SurrealFS repository. [Limits and caveats](/docs/agent-filesystem/operations/limits-and-caveats) lists the known defects and the parts that are not finished.

## Where to start

If you are new to Agent Filesystem, start with [What is Agent Filesystem?](/docs/agent-filesystem/welcome/what-is-agent-filesystem). If you already use [SurrealDB Agent Memory](/docs/agent-memory), start with [Agent Filesystem and Agent Memory](/docs/agent-filesystem/welcome/agent-filesystem-and-agent-memory), which compares the two products and shows how they work together.

| If you want to | Start with |
| --- | --- |
| Understand what an agent can do with the filesystem | [What is Agent Filesystem?](/docs/agent-filesystem/welcome/what-is-agent-filesystem) |
| See how the table, the schema, the clients and the tools fit together | [Agent Filesystem architecture](/docs/agent-filesystem/welcome/architecture) |
| Choose between Agent Filesystem and Agent Memory, or use both | [Agent Filesystem and Agent Memory](/docs/agent-filesystem/welcome/agent-filesystem-and-agent-memory) |
| Use the filesystem from Python code | [Python quickstart](/docs/agent-filesystem/quickstarts/python) |
| Use the filesystem from a terminal with the Rust command-line tool, which needs a Rust toolchain | [Command-line quickstart](/docs/agent-filesystem/quickstarts/command-line) |
| Give the filesystem to Claude or another MCP client | [MCP and Claude quickstart](/docs/agent-filesystem/quickstarts/mcp-and-claude) |

Agent Filesystem is the name of the product. The name SurrealFS appears in package names, commands and variables, because it is the name of the project repository. [Names](/docs/agent-filesystem/welcome/what-is-agent-filesystem#names) lists the identifiers.
