# Connect via CLI

The [SurrealDB CLI](/docs/reference/cli/surrealdb-cli/overview) gives you an interactive SurrealQL shell against an instance, which is the fastest route for ad-hoc queries, checking a schema definition, or scripting a one-off change.

## Prerequisites

Install the CLI — see the [installation guide](/docs/running/installation). It is a single executable and does not need a local server.

## Open a shell

[`surreal sql`](/docs/reference/cli/surrealdb-cli/commands/sql) connects to the endpoint and drops you into a prompt:

```bash title="Connect to an instance"
surreal sql \
  --endpoint wss://<endpoint> \
  --ns main --db main \
  --token <token>
```

The instance's **Connect** menu in [SurrealDB Studio](https://app.surrealdb.com) generates this command with your endpoint and token filled in.

![The Connect menu in SurrealDB Studio showing the ready-made surreal sql command for an instance, with the endpoint, namespace, database, and token already populated.](~/assets/img/image/cloud/open-in-cli.png)

The `--token` value is a JSON Web Token that authenticates the session. Treat it as a credential: it grants whatever the authenticating user or access method grants, so keep it out of shell history and out of committed scripts. Where a script needs one, mint it at runtime with `surrealctl instance token` rather than storing it.

You can authenticate with `--user` and `--pass` instead if the instance has a system user defined — see [DEFINE USER](/docs/reference/query-language/statements/define/user).
