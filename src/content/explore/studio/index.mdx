# SurrealDB Studio

SurrealDB Studio is the official visual interface for managing and querying SurrealDB. It connects to any SurrealDB instance, letting you run SurrealQL, explore records, and manage schema from the web or desktop.

<Button label="Visit studio.surrealdb.com" href="https://studio.surrealdb.com" variant="surreal" />

SurrealDB Studio succeeds Surrealist, the earlier SurrealDB interface. It is the version to use with SurrealDB 4.

## Web or desktop

Studio comes as a web app and a desktop app. Both query and manage a database, and the desktop app can also start a local database for you:

| | Web app | Desktop app |
| --- | --- | --- |
| Where | [studio.surrealdb.com](https://studio.surrealdb.com) | Download from [surrealdb.com/studio](https://surrealdb.com/studio) for macOS, Windows and Linux, on Intel and ARM |
| Account | Sign in with a SurrealDB Cloud account | Optional: choose to continue without an account, and Studio keeps your connections on that computer |
| Databases it can reach | Any database served over TLS (`wss://` or `https://`), and one on the same computer | Any database, including one served over plain `ws://` or `http://` on another machine |

The difference in what each can reach comes from the browser. A page served over HTTPS, such as the web app, may only open an unencrypted connection to the computer it runs on. To connect to a database on another machine that has no TLS certificate, such as a server on your local network, use the desktop app or put the database behind TLS.
