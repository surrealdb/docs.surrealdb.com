# Cookbook

Each recipe in this section solves one application problem with a short schema, example data and the queries that do the work, tested against the current release of SurrealDB. Every recipe is based on an article, video or project from the SurrealDB community, and links back to it for the complete version.

## Recipes

- [Invitation sign-in](/docs/explore/tutorials/cookbook/invitation-sign-in) - a record access method that accepts an invitation code once, before it expires, and creates the account and team membership
- [Multi-tenant role-based access](/docs/explore/tutorials/cookbook/multi-tenant-rbac) - tenants, roles and permissions as a graph, enforced by table permissions
- [An HTTP API in the database](/docs/explore/tutorials/cookbook/http-api-in-the-database) - a JSON task API served by `DEFINE API`, with input checks and status codes
- [Prove a sports statistic](/docs/explore/tutorials/cookbook/sports-statistic) - the youngest players to start a competitive game, from record links and a subquery per player
- [IoT telemetry with outlier alerts](/docs/explore/tutorials/cookbook/iot-telemetry) - readings stored by sensor and time, summarised over windows, with an event that raises alerts
- [Context for a recommendation prompt](/docs/explore/tutorials/cookbook/recommendation-context) - purchases, returns, searches and a vector search, gathered for a language model in one query

For complete applications to clone and run, see the [demos](/docs/explore/tutorials/demos/overview). For step-by-step guides, see the [tutorials](/docs/explore/tutorials/tutorials/overview).
