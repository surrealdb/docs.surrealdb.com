# Data manipulation

The methods below create, read, update and delete records. Each one takes a table name or a record ID as its first argument. To run [SurrealQL statements](/docs/reference/query-language/statements/overview) directly, see [executing queries](/docs/reference/php/v1/concepts/executing-queries).

| Method | Description |
| --- | --- |
| [`$db->select($thing)`](#select) | Selects all records in a table, or a specific record |
| [`$db->create($thing, $data)`](#create) | Creates a record in the database |
| [`$db->insert($thing, $data)`](#insert) | Inserts one or multiple records in the database |
| [`$db->insertRelation($thing, $data)`](#insertrelation) | Inserts one or multiple relations in the database |
| [`$db->update($thing, $data)`](#update) | Replaces the data of all records in a table, or a specific record |
| [`$db->upsert($thing, $data)`](#upsert) | Creates a record if it does not exist, or updates it if it does |
| [`$db->merge($thing, $data)`](#merge) | Merges data into all records in a table, or a specific record |
| [`$db->patch($thing, $data, $diff)`](#patch) | Applies JSON Patch changes to all records in a table, or a specific record |
| [`$db->delete($thing)`](#delete) | Deletes all records in a table, or a specific record |

## `->select()` {#select}

Selects all records in a table, or a specific record, from the database.

```php title="Method Syntax"
$db->select($thing)
```

                <code>thing</code>
                <label label="required" />
            </td>
			<td colspan="2" scope="row" data-label="Type">
				<code>string</code>, <code>RecordId</code> or <code>StringRecordId</code>
			</td>
            <td colspan="2" scope="row" data-label="Description">
                The table name or a [`RecordId`](/docs/reference/php/v1/concepts/value-types#recordid) to select.
            </td>
        </tr>
    </tbody>
</table>

### Example usage
```php
// Select all records from a table
$people = $db->select('person');

// Select a specific record from a table
$person = $db->select(new RecordId('person', 'h5wxrf2ewk8xjxosxtyc'));
$person = $db->select(new StringRecordId('person:h5wxrf2ewk8xjxosxtyc'));
```

After a record is created, pass its ID to fetch it. A `StringRecordId` or a `RecordId` made with `create()` selects the same record.

```php
$person = $db->select($person->id);

// using the StringRecordId
$id = StringRecordId::create("person:tobie");
$person = $db->select($id);

// using the RecordId
$id = RecordId::create("person", "tobie");
$person = $db->select($id);
```

### Translated query
This function will run the following query in the database.

```surql
/**[test]

[[test.results]]
error = false

*/
SELECT * FROM $thing;
```

### Example usage
```php
// Create a record with a random ID
[$person] = $db->create('person');

// Create a record with a specific ID
$person = $db->create(new RecordId('person', 'tobie'), [
	"name" => 'Tobie',
	"settings" => [
		"active" => true,
		"marketing" => true,
	],
]);

// The content you are creating the record with might differ from the return type
[$record] = $db->create(
    new RecordId('person', 'tobie'),
    ["name" => "Tobie"]
);
```

The second argument is an associative array with the field names and values.

```php
$person = $db->create("person:tobie", [
	"name" => "Tobie",
	"lastname" => "Morgan Hitchcock",
	"age" => 30,
	"hobbies" => ["reading", "coding"]
]);
```

This function will run the following query in the database.

```surql notest

```

```php
		"in" => new RecordId('company', 'surreal'),
		"out" => new RecordId('role', 'cofounder'),
	],
]);
```

```php
	"name" => "Tobie",
	"lastname" => "Morgan Hitchcock",
```

            </td>

### Example usage
```php

// Update all records in a table
$people = $db->merge('person', [
	"updated_at" => new Date(),
]);

// Update a record with a specific ID
$person = $db->merge(new RecordId('person', 'tobie'), [
	"updated_at" => new Date(),
	"settings" => [
		"active" => true,
	],
]);

// The content you are merging the record with might differ from the return type
$record = $db->merge(new RecordId('person', 'tobie'), [
	"name" => 'Tobie',
]);
```

The new values are merged with the existing record, and a field that already exists is replaced with the new value. See [the RPC protocol reference](/docs/reference/protocols/rpc-protocol#merge) for more.

```php
$person = $db->merge($person->id, [
	"age" => 31
]);
```

### Translated query
This function will run the following query in the database.

```surql notest
UPDATE $thing MERGE $data;
```

```php

		[ "op" => 'replace', "path" => '/created_at',
	    "value" => new Date() ],
]);

// Update a record with a specific ID
$person = $db->patch(new RecordId('person', 'tobie'), [
		[ "op" => 'replace', "path" => '/settings/active',
	    "value" => false ],
		[ "op" => 'add', "path" => '/tags', "value" => ['developer',
	    'engineer'] ],
	[ "op" => 'remove', "path" => '/temp' ],
]);
```

This function will run the following query in the database.

```surql notest

```
