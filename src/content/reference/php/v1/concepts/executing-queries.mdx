# Executing queries

The methods below run [SurrealQL statements](/docs/reference/query-language/statements/overview) against the database, call a SurrealQL function, and keep variables on the connection that later queries can use. To read and write records with a method for each operation, see [data manipulation](/docs/reference/php/v1/concepts/data-manipulation).

| Method | Description |
| --- | --- |
| [`$db->query($query, $vars)`](#query) | Runs a set of SurrealQL statements against the database |
| [`$db->queryRaw($query, $params)`](#queryraw) | Runs SurrealQL statements and returns the raw, unprocessed response |
| [`$db->run($function, $version, $params)`](#run) | Runs a SurrealQL function on the server |
| [`$db->let($name, $value)`](#let) | Assigns a value as a parameter for this connection |
| [`$db->unset($key)`](#unset) | Removes a parameter for this connection |

## `->query()` {#query}

Runs a set of SurrealQL statements against the database.

```php title="Method Syntax"
$db->query($query, $vars)
```

### Example usage
```php
// Assign the variable on the connection
$result = $db->query(
	'CREATE person SET name = "John"; SELECT * FROM type::table($tb);',
	[ "tb" => "person" ]
);

// Get the first result from the first query
$created = $result[0]->result[0];

// Get all of the results from the second query
$people = $result[1]->result;
```

## `->queryRaw()` {#queryraw}

With `queryRaw()`, you get back the raw RPC response. In contrast to the `query()` method, this does not throw for errors that occur in individual queries, but gives those back as a string, and this includes the time it took to execute the individual queries.

```php title="Method Syntax"
$db->queryRaw($query, $params);
```

### Example usage
```php title="Example"

// Query users with the firstname "Tobie", using parameters.
$response = $db->queryRaw(
	'SELECT * FROM users WHERE firstname = $firstname',
	['firstname' => 'Tobie']
);

// The same query without parameters.
$response = $db->queryRaw('SELECT * FROM users WHERE firstname = "Tobie"');
```

## `->run()` {#run}

Runs a defined SurrealQL function on the remote database.


### Example usage
```php title="Example"
$functionA = $db->run("fn::hello_world", null, ["Tobie"]);
$functionB = $db->run("fn::hello_world", "v1", ["Tobie"]);

// or with named arguments
$functionA = $db->run("fn::hello_world", params: ["Tobie"]);
$functionB = $db->run("fn::hello_world", version: "v1", params: ["Tobie"]);
```

## `->let()` {#let}

Assigns a value as a parameter for this connection.

```php title="Method Syntax"
$db->let($name, $value)
```

                Assigns the value to the variable name.
            </td>
        </tr>
    </tbody>
</table>

### Example usage
```php
// Assign the variable on the connection
$db->let('name', [
	"first" => "Tobie",
	"last" => "Morgan Hitchcock",
]);

// Use the variable in a subsequent query
$db->query('CREATE person SET name = $name');

// Use the variable in a subsequent query
$db->query('SELECT * FROM person WHERE name.first = $name.first');
```
