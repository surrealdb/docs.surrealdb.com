# Go SDK

The SurrealDB SDK for Go lets you connect to SurrealDB from servers, command-line tools, APIs and other Go programs. It connects to a remote instance over WebSocket or HTTP and sends SurrealQL as CBOR.

Queries and record operations are generic functions, such as `surrealdb.Query[T]` and `surrealdb.Select[T]`. Each one decodes the result into the Go type that you give.

Use the SDK to run queries, read and write records, and sign users in. You can also keep their tokens fresh, receive changes with live queries, and group statements in interactive transactions.

> [!IMPORTANT]
> The SDK requires Go `1.24` or later. It is available as a [Go module](https://pkg.go.dev/github.com/surrealdb/surrealdb.go/v2), and its module path is `github.com/surrealdb/surrealdb.go/v2`.

> [!NOTE]
> The latest version of the SDK is <Version sdk="golang" />. It works with SurrealDB 3.3.0 and later versions before 5.0.0. SurrealDB 4.0 is the recommended version. The current SurrealDB release is <Version />.

Before you upgrade a project from version 1 of the SDK, read [Migrating to Go SDK 2.x](/docs/reference/golang/migrating-to-2x). Version 2 changes the module path, the supported server versions, and how the SDK sends some Go values to the server.

## Concepts

- [Connecting to SurrealDB](/docs/reference/golang/concepts/connecting-to-surrealdb) - open a connection over WebSocket or HTTP, with options and a version check
- [Authentication](/docs/reference/golang/concepts/authentication) - sign up, sign in, and keep a token fresh
- [Executing queries](/docs/reference/golang/concepts/executing-queries) - send SurrealQL, call functions and `DEFINE API` endpoints
- [Data manipulation](/docs/reference/golang/concepts/data-manipulation) - create, select, update, upsert, patch, relate and delete records
- [Live queries](/docs/reference/golang/concepts/live-queries) - receive changes as they happen
- [Error handling](/docs/reference/golang/concepts/error-handling) - what a failure looks like, and how to check it
- [Value types](/docs/reference/golang/concepts/value-types) - how SurrealDB's types map onto Go ones
