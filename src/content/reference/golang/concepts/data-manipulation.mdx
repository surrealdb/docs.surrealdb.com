# Data manipulation

The Go SDK has a generic function for each common operation on records: [`Select`](/docs/reference/golang/api/core/db#select), [`Create`](/docs/reference/golang/api/core/db#create), [`Insert`](/docs/reference/golang/api/core/db#insert), [`Update`](/docs/reference/golang/api/core/db#update), [`Upsert`](/docs/reference/golang/api/core/db#upsert), [`Merge`](/docs/reference/golang/api/core/db#merge), [`Patch`](/docs/reference/golang/api/core/db#patch), [`Delete`](/docs/reference/golang/api/core/db#delete), [`Relate`](/docs/reference/golang/api/core/db#relate) and [`InsertRelation`](/docs/reference/golang/api/core/db#insertrelation). Each one sends a SurrealQL statement and decodes the result into the Go type that you pass as its type parameter. All of them work with a [`*DB`](/docs/reference/golang/api/core/db), a [`*Session`](/docs/reference/golang/api/core/session) or a [`*Transaction`](/docs/reference/golang/api/core/transaction). This page covers how to target records and how to use each function.

## Targeting records and tables

The functions that take a `what` argument accept a [`models.RecordID`](/docs/reference/golang/api/values/record-id), a [`models.Table`](/docs/reference/golang/api/values/table), a `string`, or a slice of record IDs or tables. The value that you pass decides what the statement works on and the shape of its result:

| `what` | Works on | Result |
| --- | --- | --- |
| `models.NewRecordID("person", "tobie")` | One record | The record, or `nil` when it does not exist |
| `models.Table("person")` | Every record in the table | A slice of records |
| `"person"` | Every record in the table, or one new record for `Create` | A slice of records, or the created record for `Create` |
| A `models.RecordID` whose ID is a [`models.Range`](/docs/reference/golang/api/values/range) | The records in the range | A slice of records |
| `[]models.RecordID`, `[]models.Table` | Each record or table in the slice | A slice of records |

A string is always a table name. The SDK never reads a string as a record ID. `"person:tobie"` names a table called `person:tobie`, so `Select` returns the error `The table 'person:tobie' does not exist`. Use `models.NewRecordID` for a record. When the ID arrives as text, [`models.ParseRecordID`](/docs/reference/golang/api/values/record-id#parserecordid) parses it. But `ParseRecordID` always makes a string ID, so the ID does not match a record whose ID is a number.

Match the type parameter to the result. For a single record, pass the record type, such as `Person`. For a table, a range or a slice, pass a slice, such as `[]Person`. If the types do not match, the SDK cannot decode the result and returns an error such as `cannot decode array into main.Person`. The examples on this page use this type:

```go
type Person struct {
	ID      *models.RecordID `json:"id,omitempty"`
	Name    string           `json:"name"`
	Surname string           `json:"surname,omitempty"`
	Age     int              `json:"age,omitempty"`
}
```

Use `*models.RecordID` with `omitempty` for the `id` field. You can then send the struct without an ID, and read it back with one.

## Selecting records

`Select` reads one record, the records of a table, or the records in a range:

```go
people, err := surrealdb.Select[[]Person](ctx, db, models.Table("person"))
if err != nil {
	log.Fatal(err)
}

tobie, err := surrealdb.Select[Person](ctx, db, models.NewRecordID("person", "tobie"))
if err != nil {
	log.Fatal(err)
}
if tobie == nil {
	fmt.Println("no such person")
}
```

When the record does not exist, `Select` returns `nil` and no error.

## Selecting a range of records

To select the records whose IDs fall in a range, pass a `models.RecordID` whose ID is a [`models.Range`](/docs/reference/golang/api/values/range). The example below selects `reading:2` and `reading:3`, from `2` included to `4` excluded:

```go
rng := models.RecordID{
	Table: "reading",
	ID: models.Range[int, models.BoundIncluded[int], models.BoundExcluded[int]]{
		Begin: &models.BoundIncluded[int]{Value: 2},
		End:   &models.BoundExcluded[int]{Value: 4},
	},
}

readings, err := surrealdb.Select[[]map[string]any](ctx, db, rng)
```

A `nil` `Begin` or `End` leaves that side of the range open. The [query builder](/docs/reference/golang/concepts/query-builder) has helpers that build the range for you, such as `surrealql.RangeBeginInclusiveEndExclusive(2, 4)`. For an array ID such as `temp:['London', 'West', 1]`, use `models.None` as the lowest value of a part, as in `[]any{"London", models.None, models.None}`.

## Creating records

`Create` creates a record from a struct or a map. To choose the ID, pass a `models.RecordID`. To let SurrealDB generate the ID, pass the table name as a string. Both forms return the created record:

```go
tobie, err := surrealdb.Create[Person](ctx, db, models.NewRecordID("person", "tobie"), Person{
	Name:    "Tobie",
	Surname: "Morgan Hitchcock",
	Age:     35,
})

jaime, err := surrealdb.Create[Person](ctx, db, "person", Person{Name: "Jaime"})
fmt.Println(jaime.ID)
```

```text title="Sample output"
person:1wxlej6yf7cvn3t27m0f
```

With a `models.Table`, `Create` returns a slice, so pass `[]Person` as the type parameter. If you pass `nil` data, `Create` creates a record with no fields other than its ID.

To ignore the result, pass `struct{}` as the type parameter:

```go
_, err := surrealdb.Create[struct{}](ctx, db, "person", Person{Name: "Ana"})
```

## Inserting records

`Insert` inserts one record or a slice of records into a table, and always returns a slice:

```go
inserted, err := surrealdb.Insert[Person](ctx, db, models.Table("person"), []Person{
	{Name: "Alice", Age: 30},
	{Name: "Bob", Age: 25},
})
fmt.Println(len(*inserted))
```

```text title="Output"
2
```

The type parameter of `Insert` is the type of one record. The function returns `*[]T`. A record in the data can have its own `id`. `Insert` cannot create a relation: use [`InsertRelation`](#inserting-relations) for that.

## Replacing records

`Update` replaces the whole content of existing records with the data you pass. It removes the fields that the data leaves out:

```go
updated, err := surrealdb.Update[Person](ctx, db, models.NewRecordID("person", "tobie"), Person{
	Name: "Tobie",
})
```

> [!NOTE]
> `Update` performs a full replacement, so it removes the `surname` and `age` of `person:tobie`. Use [`Merge`](#merging-data-into-records) to change some fields and keep the others.

`Update` changes only records that exist, and creates nothing. On a table, it updates every record. Use `Upsert` to create the record when it is missing.

## Upserting records

`Upsert` creates a record when it does not exist, and replaces its content when it does:

```go
ana, err := surrealdb.Upsert[Person](ctx, db, models.NewRecordID("person", "ana"), Person{
	Name: "Ana",
	Age:  16,
})
```

## Merging data into records

`Merge` merges the data you pass into existing records, and keeps the fields that the data does not mention:

```go
merged, err := surrealdb.Merge[Person](ctx, db, models.NewRecordID("person", "tobie"), map[string]any{
	"age": 36,
})
```

A merge into a table changes every record in the table, and returns a slice:

```go
everyone, err := surrealdb.Merge[[]Person](ctx, db, models.Table("person"), map[string]any{
	"active": true,
})
```

## Applying JSON Patch operations

`Patch` applies [JSON Patch](https://jsonpatch.com/) operations to a record, and returns the operations that changed it. Each operation is a [`PatchData`](/docs/reference/golang/api/types#patchdata) with an `Op`, a `Path` and a `Value`:

```go
changes, err := surrealdb.Patch(ctx, db, models.NewRecordID("person", "tobie"), []surrealdb.PatchData{
	{Op: "replace", Path: "/age", Value: 37},
	{Op: "add", Path: "/verified", Value: true},
})
```

The operations are `add`, `remove`, `replace`, `move`, `copy` and `test`. `Patch` returns `*[]PatchData`, which fits the result for one record. For a table, the result holds the changes of each record, so use `PatchWithResult`.

## Choosing what a patch returns

`PatchWithResult` applies JSON Patch operations in the same way as `Patch`. It returns what its last argument asks for:

| `ReturnMode` | Returns |
| --- | --- |
| `surrealdb.ReturnAfter` | The records after the change |
| `surrealdb.ReturnBefore` | The records before the change |
| `surrealdb.ReturnDiff` | The JSON Patch operations that changed each record |
| `surrealdb.ReturnNone` | Nothing: the result is `nil` |

```go
patched, err := surrealdb.PatchWithResult[Person](ctx, db,
	models.NewRecordID("person", "tobie"),
	[]surrealdb.PatchData{{Op: "replace", Path: "/age", Value: 38}},
	surrealdb.ReturnAfter,
)
fmt.Println(patched.Age)
```

```text title="Output"
38
```

For a table, use a slice as the type parameter, such as `[]Person` for `ReturnAfter`, or `[][]surrealdb.PatchData` for `ReturnDiff`:

```go
diffs, err := surrealdb.PatchWithResult[[][]surrealdb.PatchData](ctx, db,
	models.Table("person"),
	[]surrealdb.PatchData{{Op: "replace", Path: "/active", Value: false}},
	surrealdb.ReturnDiff,
)
```

## Deleting records

`Delete` deletes a record, the records of a table, or a range of records. It returns the records as they were before the delete:

```go
deleted, err := surrealdb.Delete[Person](ctx, db, models.NewRecordID("person", "ana"))

everyone, err := surrealdb.Delete[[]Person](ctx, db, models.Table("person"))
```

## Relating records

`Relate` creates an edge in a relation table, from one record to another, with a generated ID. Describe the edge with a [`Relationship`](/docs/reference/golang/api/types#relationship):

```go
edge, err := surrealdb.Relate[map[string]any](ctx, db, &surrealdb.Relationship{
	In:       models.NewRecordID("person", "tobie"),
	Out:      models.NewRecordID("person", "jaime"),
	Relation: models.Table("knows"),
	Data:     map[string]any{"since": 2020},
})
```

`Relate` ignores the `ID` field of the `Relationship`. This field exists so that the SDK can decode an edge into the struct.

## Inserting relations

`InsertRelation` inserts an edge, as `INSERT RELATION` does. If the `Relationship` has an `ID`, `InsertRelation` uses that ID. Otherwise, it generates an ID. It returns a slice:

```go
id := models.NewRecordID("knows", "tobie_jaime")

edges, err := surrealdb.InsertRelation[[]map[string]any](ctx, db, &surrealdb.Relationship{
	ID:       &id,
	In:       models.NewRecordID("person", "tobie"),
	Out:      models.NewRecordID("person", "jaime"),
	Relation: models.Table("knows"),
})
```

When you only need the ID of the edge, decode into `[]connection.ResponseID[models.RecordID]`.
