# Value types

The Go SDK sends values to SurrealDB as CBOR, and decodes the values it receives into the Go types you choose. Most SurrealDB types map onto ordinary Go types, such as `string`, `int64` and `map[string]any`. The others have a type in the `models` package, such as [`models.RecordID`](/docs/reference/golang/api/values/record-id) and [`models.PlainDate`](/docs/reference/golang/api/values/temporal). This page lists how each type converts, and covers the types that need care.

## How values convert

The first column is what you send. The last column is what a value decodes into when the target is `any`, as it is in a `map[string]any` or a `[]any`. A struct field of a concrete type, such as `Age int`, takes any value that converts to it.

| Go value | SurrealDB type | Decoded into `any` as |
| --- | --- | --- |
| `nil`, a `nil` pointer | `NULL` | `nil` |
| [`models.None`](#none-and-null) | `NONE` | `nil` |
| `bool` | `bool` | `bool` |
| `int`, `int64` | `int` | `uint64` for a value of zero or more, `int64` for a negative one |
| `float64` | `float` | `float64` |
| `string` | `string` | `string` |
| `[]byte` | `bytes` | `[]byte` |
| `[]T`, `[]any` | `array` | `[]any` |
| `map[string]any`, a struct | `object` | `map[string]any` |
| `time.Time`, `models.CustomDateTime` | `datetime`, or `NONE` for a zero time | `models.CustomDateTime` |
| `time.Duration`, `models.CustomDuration` | `duration` | `models.CustomDuration` |
| `models.DecimalString` | `decimal` | `models.DecimalString` |
| `models.UUID` | `uuid` | `models.UUID` |
| `models.RecordID` | `record` | `models.RecordID` |
| `models.Table` | `table` | `models.Table` |
| `models.Set` | `set` | `models.Set` |
| `models.File` | `file` | `models.File` |
| `models.GeometryPoint` and the other geometry types | `geometry` | The same type |
| `models.Range` | `range` | |
| `regexp.Regexp`, `*regexp.Regexp` | Not sent: encoding fails. Use `models.Regex`. | |

The kinds that SurrealDB 4.0 adds, such as sized numbers and dates, are in [SurrealDB 4.0 kinds](#surrealdb-40-kinds). The SDK matches struct fields by their `json` tags, and `omitempty` leaves a field out when it holds its zero value.

## cbor.2 and plain CBOR

The SDK uses one of two versions of the CBOR protocol: cbor.2 with SurrealDB 4.0, and plain CBOR with earlier servers. It offers cbor.2 when it connects. [`db.CBORVersion()`](/docs/reference/golang/api/core/db#cborversion) reports which version a connection uses. The two versions differ only for the kinds that SurrealDB 4.0 adds, which plain CBOR cannot carry. Over plain CBOR, the SDK and the server send each of these kinds as the nearest older kind. They cannot send a regex at all.

To keep plain CBOR with a SurrealDB 4.0 server, set `DisableCBORv2` in the [connection configuration](/docs/reference/golang/concepts/connecting-to-surrealdb#using-a-custom-connection).

## Record IDs and tables

A [`models.RecordID`](/docs/reference/golang/api/values/record-id) holds a table name and an ID. Build one with `models.NewRecordID`, or receive one in a result. The ID can be a string, a number, an array or an object:

```go
import "github.com/surrealdb/surrealdb.go/v2/pkg/models"

id := models.NewRecordID("person", "tobie")
numeric := models.NewRecordID("event", 42)
compound := models.NewRecordID("temperature", []any{"London", 2026})
```

To read a record ID from text such as `"person:tobie"`, use `models.ParseRecordID`. It always makes a string ID, so `"event:42"` becomes `event:⟨42⟩` rather than `event:42`. In a struct, use `*models.RecordID` with `omitempty` for the `id` field, so that you can send the struct without an ID:

```go
type Person struct {
	ID   *models.RecordID `json:"id,omitempty"`
	Name string           `json:"name"`
}
```

A plain `string` given as the target of a CRUD function is always a table name, even when it holds a `:`. See [Targeting records and tables](/docs/reference/golang/concepts/data-manipulation#targeting-records-and-tables).

## NONE and NULL

SurrealDB keeps `NONE` and `NULL` apart. `NONE` is a value that does not exist, and `NULL` is a value that exists and is empty. The SDK sends `nil` and a `nil` pointer as `NULL`, and `models.None` as `NONE`. Both decode into `nil`:

```go
_, err := surrealdb.Create[map[string]any](ctx, db, models.NewRecordID("person", "tobie"), map[string]any{
	"nickname": models.None,
	"manager":  nil,
})
```

Here the server does not store `nickname` at all, and it stores `manager` as `NULL`. A field defined as `option<string>` accepts `NONE`, and one defined as `string | null` accepts `NULL`.

The SDK sends a zero `time.Time` as `NONE`, so a struct field of type `time.Time` that you never set leaves the field out. The new `models` types of SurrealDB 4.0 work differently. Their zero value is a real value, such as the date 1970-01-01, rather than `NONE`. For an optional field of one of those types, use a pointer with `omitempty`.

## Datetimes

Send a `time.Time` as it is. The SDK sends it as a SurrealDB `datetime` with its nanoseconds, and a zero `time.Time` as `NONE`:

```go
type Event struct {
	ID        *models.RecordID `json:"id,omitempty"`
	StartedAt time.Time        `json:"started_at"`
}

_, err := surrealdb.Create[Event](ctx, db, "event", Event{StartedAt: time.Now()})
```

A datetime decodes into a `time.Time` field, or into a [`models.CustomDateTime`](/docs/reference/golang/api/values/datetime) when the target is `any`. `CustomDateTime` embeds `time.Time`, so it has the same methods. To store `NULL` rather than `NONE` for a missing time, use a `*time.Time` that is `nil`.

## Durations

Send a `time.Duration` as it is. The SDK sends it as a SurrealDB `duration`:

```go
type Job struct {
	ID      *models.RecordID `json:"id,omitempty"`
	Timeout time.Duration    `json:"timeout"`
}

_, err := surrealdb.Create[Job](ctx, db, "job", Job{Timeout: 90 * time.Second})
```

A duration decodes into a `time.Duration` field, or into a [`models.CustomDuration`](/docs/reference/golang/api/values/duration) when the target is `any`. Version 1 of the SDK stored a `time.Duration` as an `int` of nanoseconds. A value stored this way also decodes into a `time.Duration` field.

## Numbers and decimals

The SDK sends a Go `int`, `int64` or `float64` as a SurrealDB `int` or `float`. It sends a `uint64` above `math.MaxInt64` as a `u64` over cbor.2, and as a `decimal` over plain CBOR. A SurrealDB `decimal` decodes into a [`models.DecimalString`](/docs/reference/golang/api/values/numbers#decimalstring), which keeps its digits as text. The next section and the [Numbers](/docs/reference/golang/api/values/numbers) page cover the sized numbers and `bigdecimal` of SurrealDB 4.0.

## SurrealDB 4.0 kinds

SurrealDB 4.0 adds sized numbers, `bigdecimal`, the calendar kinds `date`, `time`, `timestamp` and `interval`, and `regex`. Over cbor.2, each kind keeps its type when you send it and when you receive it. It decodes into `any` as the Go type in the second column. Over plain CBOR, the SDK and the server send the nearest older kind:

| SurrealQL | Go type | Over plain CBOR |
| --- | --- | --- |
| `i8`, `u8`, `i16`, `u16`, `i32`, `u32` | `int8`, `uint8`, `int16`, `uint16`, `int32`, `uint32` | `int` |
| `u64` | `uint64` above `math.MaxInt64` | `decimal` |
| `f16` | [`models.Float16`](/docs/reference/golang/api/values/numbers#float16) | `float` |
| `f32` | `float32` | `float` |
| `bigdecimal` | [`models.BigDecimal`](/docs/reference/golang/api/values/numbers#bigdecimal) | `decimal` when the value fits one, otherwise its text |
| `date` | [`models.PlainDate`](/docs/reference/golang/api/values/temporal#plaindate) | A `datetime` at midnight UTC |
| `time` | [`models.PlainTime`](/docs/reference/golang/api/values/temporal#plaintime) | The `duration` since midnight |
| `timestamp` | [`models.Timestamp`](/docs/reference/golang/api/values/temporal#timestamp) | A `datetime`, with the wall clock read as UTC |
| `interval` | [`models.Interval`](/docs/reference/golang/api/values/temporal#interval) | Its ISO 8601 text |
| `regex` | [`models.Regex`](/docs/reference/golang/api/values/regex) | Not sent: encoding fails with `constants.ErrNeedsCBOR2` |

```go
results, err := surrealdb.Query[[]any](ctx, db,
	"RETURN [type::of($level), type::of($score), type::of($due)]",
	map[string]any{
		"level": int8(5),
		"score": float32(1.5),
		"due":   models.MustParsePlainDate("2024-02-29"),
	},
)
fmt.Println((*results)[0].Result)
```

```text title="Output with SurrealDB 4.0"
[i8 f32 date]
```

Against a SurrealDB 3.x server, the same query prints `[int float datetime]`. You can also decode a value of one of these kinds into a Go type other than its own. The value then decodes in the form that plain CBOR carries. For example, a `date` decodes into a `time.Time` as midnight UTC on that date.

When you send a Go `int8`, the server stores it as an `i8`, so a later read into `any` gives an `int8` back. Code that asserts the type of a decoded number, such as `v.(uint64)`, has to allow for the sized types. Decoding into a struct field of a concrete type converts every numeric kind.

## Sets

A SurrealDB `set` holds distinct values in order. To send a set, build a [`models.Set`](/docs/reference/golang/api/values/set) with `models.NewSet`. The server sorts it and removes duplicates:

```go
results, err := surrealdb.Query[models.Set](ctx, db, "RETURN $tags", map[string]any{
	"tags": models.NewSet("go", "db", "go"),
})
fmt.Println((*results)[0].Result)
```

```text title="Output"
[db go]
```

A set decodes into `any` as a `models.Set`, so a set that you read and write back stays a set. It also decodes into a slice of a concrete type, such as `[]string`.

## Regular expressions

A [`models.Regex`](/docs/reference/golang/api/values/regex) holds the text of a pattern, which the server compiles with the syntax of the Rust `regex` crate:

```go
results, err := surrealdb.Query[bool](ctx, db, "RETURN $name = $pattern", map[string]any{
	"name":    "tobie",
	"pattern": models.Regex{Pattern: "^[a-z]+$"},
})
```

The SDK never compiles a pattern. It also refuses to send a Go `*regexp.Regexp`, because the Go syntax is not the same. A regex needs SurrealDB 4.0.

## Geometry

The SDK has a type for each GeoJSON geometry. [`models.GeometryPoint`](/docs/reference/golang/api/values/geometry) holds a longitude and a latitude, and you build the other types from points:

```go
point := models.GeometryPoint{Longitude: -0.118, Latitude: 51.509}

line := models.GeometryLine{
	{Longitude: -0.118, Latitude: 51.509},
	{Longitude: -0.076, Latitude: 51.508},
}
```

## Files

A [`models.File`](/docs/reference/golang/api/values/file) points to a file in a bucket, as the SurrealQL value `f"bucket:/key"` does. Build one with `models.NewFile("docs", "/report.pdf")`. Send it as a variable.

## Ranges

A [`models.Range`](/docs/reference/golang/api/values/range) holds two bounds, each included or excluded. Use it as the ID of a `models.RecordID` to [select a range of records](/docs/reference/golang/concepts/data-manipulation#selecting-a-range-of-records).
