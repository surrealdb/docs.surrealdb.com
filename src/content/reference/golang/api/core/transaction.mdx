# `Transaction` {#transaction}

A `Transaction` is an interactive transaction on a WebSocket connection. Unlike a text transaction, it runs statements one at a time, so your code can read each result and then commit or cancel. Every query and CRUD function, such as [`Query`](/docs/reference/golang/api/core/db#query), [`Select`](/docs/reference/golang/api/core/db#select) and [`QueryStream`](/docs/reference/golang/api/core/db#querystream), takes a `*Transaction` in place of a `*DB`. See [Transactions](/docs/reference/golang/concepts/transactions) for explanations and examples.

A transaction runs as the signed-in user of its session, in the namespace and database of that session. A transaction cannot change that state. For this reason, it has no `SignIn`, `Use` or `Let` methods, and `Live` and `Kill` do not take it. When the client loses the connection, it also loses any open transaction.

**Source:** [transaction.go](https://github.com/surrealdb/surrealdb.go/blob/main/transaction.go)

## Creating a transaction

### `db.Begin()` {#db-begin}

Starts a transaction in the default session.

```go title="Syntax"
tx, err := db.Begin(ctx)
```

**Returns:** `(*Transaction, error)`. On an HTTP connection, the error is [`constants.ErrTransactionsNotSupported`](/docs/reference/golang/api/errors#sentinel-errors).

### `session.Begin()` {#session-begin}

Starts a transaction in a [session](/docs/reference/golang/api/core/session).

```go title="Syntax"
tx, err := session.Begin(ctx)
```

**Returns:** `(*Transaction, error)`. After `session.Detach()`, the error is [`constants.ErrSessionClosed`](/docs/reference/golang/api/errors#sentinel-errors).

```go
tx, err := db.Begin(ctx)
if err != nil {
	log.Fatal(err)
}
defer tx.Cancel(ctx)

if _, err := surrealdb.Create[any](ctx, tx, "event", map[string]any{
	"type":   "transfer",
	"amount": 100,
}); err != nil {
	log.Fatal(err)
}

if err := tx.Commit(ctx); err != nil {
	log.Fatal(err)
}
```

## Properties

### `.ID()` {#id}

Returns the UUID of the transaction.

```go title="Syntax"
id := tx.ID()
```

**Returns:** [`*models.UUID`](/docs/reference/golang/api/values/uuid)

### `.SessionID()` {#sessionid}

Returns the UUID of the session that started the transaction, or `nil` for a transaction in the default session.

```go title="Syntax"
sessionID := tx.SessionID()
```

**Returns:** [`*models.UUID`](/docs/reference/golang/api/values/uuid)

### `.IsClosed()` {#isclosed}

Reports whether the transaction was committed or cancelled.

```go title="Syntax"
closed := tx.IsClosed()
```

**Returns:** `bool`

---

## Methods

### `.Commit()` {#commit}

Commits the transaction, and makes its changes permanent. After that, you cannot use the transaction.

```go title="Syntax"
err := tx.Commit(ctx)
```

**Returns:** `error`. For a transaction that was already committed or cancelled, the error is [`constants.ErrTransactionClosed`](/docs/reference/golang/api/errors#sentinel-errors). When another transaction changed the same data, [`surrealdb.IsTransactionConflict`](/docs/reference/golang/api/errors#kind-helpers) reports the conflict, and you can run the transaction again.

### `.Cancel()` {#cancel}

Cancels the transaction, and discards its changes. After that, you cannot use the transaction.

```go title="Syntax"
err := tx.Cancel(ctx)
```

**Returns:** `error`

On a transaction that was already committed or cancelled, `.Cancel()` returns `constants.ErrTransactionClosed` and changes nothing. This makes `defer tx.Cancel(ctx)` safe directly after `.Begin()`.
