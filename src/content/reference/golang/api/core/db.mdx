# `DB` {#db}

`DB` is the client of the Go SDK. It holds the connection and the default session, and has methods for connecting, [authentication](/docs/reference/golang/concepts/authentication), variables, sessions, transactions, and import and export. Queries and record operations are generic package functions, such as `surrealdb.Query[T]`, that take a `*DB`, a [`*Session`](/docs/reference/golang/api/core/session) or a [`*Transaction`](/docs/reference/golang/api/core/transaction) as their `s` argument. This page is the reference for both. For explanations and longer examples, follow the links to the concept pages.

```go title="Import"
import surrealdb "github.com/surrealdb/surrealdb.go/v2"
```

**Source:** [db.go](https://github.com/surrealdb/surrealdb.go/blob/main/db.go)

## Constructors

### `FromEndpointURLString` {#fromendpointurlstring}

Creates a client and connects it. The scheme of the URL chooses the connection: `ws://` and `wss://` for WebSocket, `http://` and `https://` for HTTP.

```go title="Syntax"
db, err := surrealdb.FromEndpointURLString(ctx, connectionURL)
```

**Returns:** `(*DB, error)`

```go
db, err := surrealdb.FromEndpointURLString(ctx, "ws://localhost:8000")
if err != nil {
	log.Fatal(err)
}
defer db.Close(ctx)
```

A URL with another scheme returns `invalid connection url`. For `mem://`, `memory` and `surrealkv://`, the function returns `embedded database not enabled`. See [Connecting to SurrealDB](/docs/reference/golang/concepts/connecting-to-surrealdb).

### `FromEndpointURLStringWithOptions` {#fromendpointurlstringwithoptions}

Creates a client and connects it, configured by [options](#options). With no options, it does what `FromEndpointURLString` does.

```go title="Syntax"
db, err := surrealdb.FromEndpointURLStringWithOptions(ctx, connectionURL, opts...)
```

**Returns:** `(*DB, error)`

```go
db, err := surrealdb.FromEndpointURLStringWithOptions(ctx, "ws://localhost:8000",
	surrealdb.WithVersionCheck(true),
	surrealdb.WithTokenRenewal(true),
)
```

### `FromConnection` {#fromconnection}

Creates a client from a connection you built, such as `gorillaws.New(conf)`, `gws.New(conf)` or `http.New(conf)`, and calls `.Connect(ctx)` on it.

```go title="Syntax"
db, err := surrealdb.FromConnection(ctx, conn)
```

### `FromConnectionWithOptions` {#fromconnectionwithoptions}

Creates a client from a connection you built, configured by [options](#options).

```go title="Syntax"
db, err := surrealdb.FromConnectionWithOptions(ctx, conn, opts...)
```

**Returns:** `(*DB, error)`

`Connect`, `New` and `.WithContext()` are deprecated. Use `FromEndpointURLString`, and pass a context to each call.

## Options {#options}

An `Option` configures a client created with `FromEndpointURLStringWithOptions` or `FromConnectionWithOptions`.

### `WithVersionCheck` {#withversioncheck}

Turns the check of the server version on or off. It is off by default. When it is on, the client sends a version request each time it connects. Connecting fails with an [`UnsupportedVersionError`](/docs/reference/golang/api/errors#unsupportedversionerror) when the server version is outside [`MinimumServerVersion`](#version-constants) to `MaximumServerVersion`. Connecting also fails when the server does not answer the version request.

```go title="Syntax"
surrealdb.WithVersionCheck(enabled bool) Option
```

### `WithReconnect` {#withreconnect}

Turns reconnection on or off. It is on by default for WebSocket connections. When the client loses the connection, it connects again, with backoff. Before it sends any other request, it restores the sessions, authentication, namespaces, databases, variables and live queries. See [Reliable connections](/docs/reference/golang/concepts/reliable-connections).

```go title="Syntax"
surrealdb.WithReconnect(enabled bool) Option
```

### `WithReconnectAttempts` {#withreconnectattempts}

Sets how many consecutive attempts the client makes to reconnect before it gives up and closes. It defaults to `DefaultReconnectAttempts`, which is `5`. Zero or less means no limit.

```go title="Syntax"
surrealdb.WithReconnectAttempts(attempts int) Option
```

### `WithReconnectDelay` {#withreconnectdelay}

Sets the wait before each attempt to reconnect. The wait is `minDelay` times 2 to the power of the attempt's number, counting from 1. It has up to 10% jitter, and is at most `maxDelay`. `minDelay` and `maxDelay` default to `DefaultReconnectMinDelay` (`1s`) and `DefaultReconnectMaxDelay` (`1m`).

```go title="Syntax"
surrealdb.WithReconnectDelay(minDelay, maxDelay time.Duration) Option
```

### `WithTokenRenewal` {#withtokenrenewal}

Turns automatic token renewal on or off. It is off by default. When it is on, a session that holds a token pair exchanges the pair for a new one shortly before the access token expires. A session gets a token pair from `.SignInWithRefresh()`, `.SignUpWithRefresh()` or `.Refresh()`. [`.Tokens()`](#tokens) returns the current pair. See [Automatic token renewal](/docs/reference/golang/concepts/authentication#automatic-token-renewal).

```go title="Syntax"
surrealdb.WithTokenRenewal(enabled bool) Option
```

### `WithTokenExpiryMargin` {#withtokenexpirymargin}

Sets the margin: the session renews an access token this long before the token expires. It defaults to `DefaultTokenExpiryMargin`, which is `1m`. When an access token lives for less than twice the margin, the session renews it halfway through its life.

```go title="Syntax"
surrealdb.WithTokenExpiryMargin(margin time.Duration) Option
```

## Connection methods

### `.Close()` {#close}

Closes the connection and releases its resources. Later requests return `ErrClientClosed`.

```go title="Syntax"
err := db.Close(ctx)
```

**Returns:** `error`

### `.Use()` {#use}

Selects the namespace and database of the default session.

```go title="Syntax"
err := db.Use(ctx, ns, database)
```

### `.Version()` {#version}

Returns the version, build and timestamp of the server.

```go title="Syntax"
ver, err := db.Version(ctx)
```

**Returns:** `(*VersionData, error)`. See [`VersionData`](/docs/reference/golang/api/types#versiondata).

### `.Health()` {#health}

Checks that the server is up. It sends `GET /health` over HTTP, whichever transport the client uses, and needs no authentication. It returns `nil` when the server answers with a `2xx` status. Otherwise, it returns a [`*HealthError`](/docs/reference/golang/api/errors#healtherror) with the status and the body.

```go title="Syntax"
err := db.Health(ctx)
```

**Returns:** `error`

### `.CBORVersion()` {#cborversion}

Returns the CBOR version the connection uses: `connection.CBORv2` (cbor.2, with SurrealDB 4.0) or `connection.CBORv1` (plain CBOR). Its `String()` method returns `cbor.2` or `cbor`. See [cbor.2 and plain CBOR](/docs/reference/golang/concepts/value-types#cbor2-and-plain-cbor).

```go title="Syntax"
v := db.CBORVersion()
```

**Returns:** `connection.CBORVersion`

### `.Status()` {#status}

Returns the state of the connection. A client that does not reconnect stays `StatusConnected` until it closes.

```go title="Syntax"
status := db.Status()
```

**Returns:** [`ConnectionStatus`](/docs/reference/golang/api/types#connectionstatus)

### `.OnStatus()` {#onstatus}

Calls `fn` with a [`StatusEvent`](/docs/reference/golang/api/types#statusevent) each time the state of the connection changes. The calls stop when you call the function that `.OnStatus()` returns. The client passes events one at a time, in order, on a goroutine other than the one that reconnects. Only a client that reconnects reports changes.

```go title="Syntax"
stop := db.OnStatus(fn func(StatusEvent))
```

**Returns:** `func()`, which stops the calls

## Authentication methods

### `.SignIn()` {#signin}

Signs in a user. The fields of `authData` decide the level: root, namespace, database, record, or a bearer key with the `key` field.

```go title="Syntax"
token, err := db.SignIn(ctx, authData)
```

            <td><code>any</code></td>
            <td>An <a href="/docs/reference/golang/api/types#auth"><code>Auth</code></a> struct, or a <code>map[string]any</code> with the keys <code>NS</code>, <code>DB</code>, <code>AC</code>, <code>user</code>, <code>pass</code>, <code>key</code>, or the fields an access method reads.</td>
        </tr>
    </tbody>
</table>

**Returns:** `(string, error)`, where the string is the JWT

```go title="Root user"
token, err := db.SignIn(ctx, surrealdb.Auth{
	Username: "root",
	Password: "secret",
})
```

```go title="Record user"
token, err := db.SignIn(ctx, map[string]any{
	"NS":    "surrealdb",
	"DB":    "docs",
	"AC":    "account",
	"email": "tobie@example.com",
	"pass":  "hunter123",
})
```

For an access method defined `WITH REFRESH`, use `.SignInWithRefresh()`.

### `.SignInWithRefresh()` {#signinwithrefresh}

Signs in through a `TYPE RECORD` access method defined `WITH REFRESH`, and returns an access token and a refresh token. To exchange a refresh token for a new pair, pass a `refresh` key in place of the credentials.

```go title="Syntax"
tokens, err := db.SignInWithRefresh(ctx, authData)
```

**Returns:** `(*Tokens, error)`. See [`Tokens`](/docs/reference/golang/api/types#tokens).

### `.SignUp()` {#signup}

Signs up a record user through the `SIGNUP` clause of an access method, and signs them in.

```go title="Syntax"
token, err := db.SignUp(ctx, authData)
```

**Returns:** `(string, error)`, where the string is the JWT

### `.SignUpWithRefresh()` {#signupwithrefresh}

Signs up a record user through an access method defined `WITH REFRESH`, and returns an access token and a refresh token.

```go title="Syntax"
tokens, err := db.SignUpWithRefresh(ctx, authData)
```

**Returns:** `(*Tokens, error)`

### `.Refresh()` {#refresh}

Exchanges a token pair for a new one, and authenticates the session with it. The server revokes the refresh token that you pass. After that, you can refresh only the returned pair.

```go title="Syntax"
newTokens, err := db.Refresh(ctx, tokens)
```

### `.Revoke()` {#revoke}

Revokes the refresh token of a pair. After that, you cannot refresh the pair. The session stays signed in.

```go title="Syntax"
err := db.Revoke(ctx, tokens)
```

**Returns:** `error`

### `.Tokens()` {#tokens}

Returns the token pair that the session holds. The pair changes at each renewal. It returns `nil` when the session holds no pair or when token renewal is off.

```go title="Syntax"
pair := db.Tokens()
```

**Returns:** `*Tokens`

### `.Authenticate()` {#authenticate}

Authenticates the connection with a JWT, such as a token from an earlier sign-in or one that a `TYPE JWT` access method verifies.

```go title="Syntax"
err := db.Authenticate(ctx, token)
```

**Returns:** `error`

### `.Invalidate()` {#invalidate}

Signs the session out. The namespace, database and variables stay as they are.

```go title="Syntax"
err := db.Invalidate(ctx)
```

**Returns:** `error`

### `.Reset()` {#reset}

Returns the default session to the state it had when the client connected. It signs the session out, clears its namespace, database and variables, and kills its live queries. Over HTTP, it clears the state that the client keeps, without calling the server.

```go title="Syntax"
err := db.Reset(ctx)
```

**Returns:** `error`

### `.Info()` {#info}

Returns the record of the signed-in record user, as `SELECT * FROM $auth` does. Table permissions apply.

```go title="Syntax"
info, err := db.Info(ctx)
```

**Returns:** `(map[string]any, error)`

## Variables

### `.Let()` {#let}

Sets a variable in the default session, which later queries can use as `$key`. Over WebSocket, the client keeps a copy of the variable, encoded once. It uses this copy to set the variable again when it reconnects, and to copy the variable to a fork.

```go title="Syntax"
err := db.Let(ctx, key, val)
```

## Sessions and transactions

### `.Attach()` {#attach}

Attaches a new session to the connection. The new session starts signed out, with no namespace or database. Needs a WebSocket connection, and returns `constants.ErrSessionsNotSupported` otherwise. See [Multiple sessions](/docs/reference/golang/concepts/multiple-sessions).

```go title="Syntax"
session, err := db.Attach(ctx)
```

**Returns:** `(*Session, error)`. See [`Session`](/docs/reference/golang/api/core/session).

### `.Fork()` {#fork}

Attaches a new session that starts as a copy of the default session. The new session has the same namespace, database and variables, and is signed in with the same access token. After that token expires, `.Fork()` returns an error that wraps `constants.ErrForkTokenExpired`. `.Fork()` does not copy a token pair. Needs a WebSocket connection.

```go title="Syntax"
session, err := db.Fork(ctx)
```

**Returns:** `(*Session, error)`

### `.Sessions()` {#sessions}

Lists the sessions attached to the connection, other than the default one, including sessions that this client did not attach. Needs a WebSocket connection.

```go title="Syntax"
sessions, err := db.Sessions(ctx)
```

**Returns:** `([]*Session, error)`

### `.Begin()` {#begin}

Starts an interactive transaction in the default session. Needs a WebSocket connection, and returns `constants.ErrTransactionsNotSupported` otherwise. See [Transactions](/docs/reference/golang/concepts/transactions).

```go title="Syntax"
tx, err := db.Begin(ctx)
```

**Returns:** `(*Transaction, error)`. See [`Transaction`](/docs/reference/golang/api/core/transaction).

## Query functions

These are generic package functions. Their `s` argument is a `*DB`, a [`*Session`](/docs/reference/golang/api/core/session) or a [`*Transaction`](/docs/reference/golang/api/core/transaction).

### `Query` {#query}

Runs SurrealQL and returns one result for each statement. When any statement fails, the error joins the [`QueryError`](/docs/reference/golang/api/errors#queryerror) of each failed statement. The function still returns the results. See [Executing queries](/docs/reference/golang/concepts/executing-queries).

```go title="Syntax"
results, err := surrealdb.Query[TResult](ctx, s, sql, vars)
```

### `QueryStream` {#querystream}

Runs SurrealQL and yields its result frame by frame while it runs, with the `query_stream` method over WebSocket. Leaving the loop early cancels the query on the server. Over HTTP, or when the server refuses `query_stream`, the function runs the query with the `query` method. It then yields the result as frames of the same form. See [Streaming results](/docs/reference/golang/concepts/streaming).

```go title="Syntax"
for frame, err := range surrealdb.QueryStream[T](ctx, s, sql, vars) {
	// ...
}
```

**Returns:** `iter.Seq2[StreamFrame[T], error]`. See [`StreamFrame`](/docs/reference/golang/api/types#streamframe).

`QueryStreamVersion` is the revision of the streaming protocol that the SDK reads. When a server announces a later revision, the stream fails with `ErrStreamProtocol`.

### `Run` {#run}

Calls a function with arguments and returns its result. The name has parts joined by `::`, such as `string::len` or `fn::greet`. It can also be one of the built-ins `count`, `not`, `rand` and `sleep`. The SDK refuses any other name before it sends a request.

```go title="Syntax"
result, err := surrealdb.Run[TResult](ctx, s, name, args...)
```

**Returns:** `(*TResult, error)`

```go
length, err := surrealdb.Run[int](ctx, db, "string::len", "SurrealDB")
```

### `RunVersion` {#runversion}

Calls a function at a version, such as the machine learning model `ml::house_price` at `1.0.0`. An empty version is the same as `Run`.

```go title="Syntax"
result, err := surrealdb.RunVersion[TResult](ctx, s, name, version, args...)
```

**Returns:** `(*TResult, error)`

### `API` {#api}

Calls an endpoint defined with `DEFINE API`, at a path such as `/users/123`, in the namespace and database of the session. A `nil` request is a `GET` without a body. A response with an unsuccessful status is not an error, so check `Status`. When the body of such a response does not fit `TBody`, `Body` is its zero value.

```go title="Syntax"
res, err := surrealdb.API[TBody](ctx, s, path, req)
```

## Data functions

These generic package functions send a SurrealQL statement with the `query` RPC method. Their `s` argument is a `*DB`, a `*Session` or a `*Transaction`. Their `what` argument is a [`TableOrRecord`](/docs/reference/golang/api/types#tableorrecord): a `models.RecordID`, a `models.Table`, a `string`, or a slice of record IDs or tables. A string is always a table name. A record ID gives one record, or `nil` when the record does not exist. A table, a range or a slice gives a slice. See [Data manipulation](/docs/reference/golang/concepts/data-manipulation).

A failed statement returns an `*RPCError` that unwraps to a [`*ServerError`](/docs/reference/golang/api/errors#servererror).

## Live query functions

`Live` and `Kill` take a `*DB` or a `*Session`, but not a `*Transaction`, because a live query belongs to a session. Live queries need a WebSocket connection. See [Live queries](/docs/reference/golang/concepts/live-queries).

### `Live` {#live}

Starts a live query on a table, and returns its UUID. When the client reconnects, the live query starts again under the same UUID, in its original namespace and database. When the session is no longer signed in as it was before, the live query ends with `ErrLiveQueryEnded` instead.

```go title="Syntax"
liveID, err := surrealdb.Live(ctx, s, table, diff)
```

### `Kill` {#kill}

Stops a live query and closes its notification channel.

```go title="Syntax"
err := surrealdb.Kill(ctx, s, id)
```

**Returns:** `error`

### `.LiveNotifications()` {#livenotifications}

Returns the notification channel of a live query of the default session. For a live query that the client ended on a reconnect, it returns `ErrLiveQueryEnded`.

```go title="Syntax"

```

**Returns:** `(chan connection.Notification, error)`. See [`Notification`](/docs/reference/golang/api/types#notification).

### `.CloseLiveNotifications()` {#closelivenotifications}

Closes the notification channel of a live query, without stopping the live query on the server.

```go title="Syntax"
err := db.CloseLiveNotifications(liveQueryID)
```

**Returns:** `error`

## Version helpers

### `MinimumServerVersion` and `MaximumServerVersion` {#version-constants}

`MinimumServerVersion` is `"3.3.0"`, the oldest SurrealDB version the SDK supports, pre-releases included. `MaximumServerVersion` is `"5.0.0"`, the first version it does not support.

### `IsVersionSupported` {#isversionsupported}

Reports whether the SDK supports a server of the given version, such as `"4.0.0"`, `"surrealdb-4.1.2"` or `"4.1.0-nightly+20261014"`. It compares only the major, minor and patch numbers.

```go title="Syntax"
ok := surrealdb.IsVersionSupported(version)
```

**Returns:** `bool`

### `IsVersionInRange` {#isversioninrange}

Reports whether a version is at least `minimum` and below `maximum`. Use it, for example, to check whether a server has a feature that a later release added. When the function cannot parse the version or a bound, it returns `false`.

```go title="Syntax"
ok := surrealdb.IsVersionInRange(version, minimum, maximum)
```

**Returns:** `bool`

```go
ver, err := db.Version(ctx)
if err == nil && surrealdb.IsVersionInRange(ver.Version, "4.1.0", surrealdb.MaximumServerVersion) {
	// use a feature that SurrealDB 4.1 added
}
```

## Low-level RPC

### `Send` {#send}

Sends an RPC request and decodes the response into `res`. It accepts only the methods `select`, `create`, `insert`, `insert_relation`, `kill`, `live`, `merge`, `relate`, `update`, `upsert`, `patch`, `delete` and `query`. It refuses other methods before it sends anything. The `res` argument is a `*connection.RPCResponse[Result]`.

```go title="Syntax"
err := surrealdb.Send[Result](ctx, db, res, method, params...)
```

**Returns:** `error`

## Availability by connection type {#availability}

| Feature | WebSocket | HTTP |
| --- | --- | --- |
| `Query`, `QueryRaw`, `Run`, `API`, `GQL`, the CRUD functions | Yes | Yes |
| Authentication, `.Use()`, `.Let()`, `.Unset()`, `.Reset()` | Yes, kept by the server | Yes, kept by the client |
| `.Health()`, `.Version()`, `.Export()`, `.Import()` | Yes | Yes |
| `QueryStream` | Yes, streamed | Yes, the whole result at once |
| `Live`, `Kill`, `.LiveNotifications()` | Yes | No |
| `.Attach()`, `.Fork()`, `.Sessions()` | Yes | No: `ErrSessionsNotSupported` |
| `.Begin()` | Yes | No: `ErrTransactionsNotSupported` |
| Reconnection and `.OnStatus()` | Yes | Not needed |
