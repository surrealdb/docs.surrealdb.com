# `Session` {#session}

A `Session` is an extra session on a WebSocket connection, with its own authentication, namespace and database, and variables. [`db.Attach()`](/docs/reference/golang/api/core/db#attach) and [`db.Fork()`](/docs/reference/golang/api/core/db#fork) return one, and [`db.Sessions()`](/docs/reference/golang/api/core/db#sessions) lists them. Every query and CRUD function, such as [`Query`](/docs/reference/golang/api/core/db#query) and [`Select`](/docs/reference/golang/api/core/db#select), takes a `*Session` in place of a `*DB`. See [Multiple sessions](/docs/reference/golang/concepts/multiple-sessions) for explanations and examples.

Sessions need a WebSocket connection. When the client reconnects, it attaches each session again under the same UUID and restores its state.

**Source:** [session.go](https://github.com/surrealdb/surrealdb.go/blob/main/session.go)

---

## Creating a session

### `db.Attach()` {#attach}

Attaches a new session to the connection. The new session starts signed out, with no namespace or database selected.

```go title="Syntax"
session, err := db.Attach(ctx)
```

**Returns:** `(*Session, error)`. On an HTTP connection, the error is `constants.ErrSessionsNotSupported`.

```go
session, err := db.Attach(ctx)
if err != nil {
	log.Fatal(err)
}
defer session.Detach(ctx)

if _, err := session.SignIn(ctx, surrealdb.Auth{Username: "root", Password: "secret"}); err != nil {
	log.Fatal(err)
}
if err := session.Use(ctx, "surrealdb", "docs"); err != nil {
	log.Fatal(err)
}

people, err := surrealdb.Query[[]Person](ctx, session, "SELECT * FROM person", nil)
```

### `.Fork()` {#fork}

Attaches a new session that starts as a copy of this one. The new session has the same namespace, database and variables, and is signed in with the same access token. After that, the two sessions are independent. `.Fork()` does not copy a token pair.

```go title="Syntax"
fork, err := session.Fork(ctx)
```

**Returns:** `(*Session, error)`

After the access token of the session expires, `.Fork()` returns an error that wraps `constants.ErrForkTokenExpired`. For a session that `db.Sessions()` lists but this client did not attach, it returns `constants.ErrForkUntracked`.

## Authentication methods

These methods work like the methods with the same name on [`DB`](/docs/reference/golang/api/core/db#authentication-methods), but only for this session.

### `.SignIn()` {#signin}

Signs a user in to this session.

```go title="Syntax"
token, err := session.SignIn(ctx, authData)
```

**Returns:** `(string, error)`

### `.SignInWithRefresh()` {#signinwithrefresh}

Signs in through a `TYPE RECORD` access method defined `WITH REFRESH`, and returns an access token and a refresh token.

```go title="Syntax"
tokens, err := session.SignInWithRefresh(ctx, authData)
```

**Returns:** [`(*Tokens, error)`](/docs/reference/golang/api/types#tokens)

### `.SignUp()` {#signup}

Signs up a record user, and signs them in to this session.

```go title="Syntax"
token, err := session.SignUp(ctx, authData)
```

**Returns:** `(string, error)`

### `.SignUpWithRefresh()` {#signupwithrefresh}

Signs up through an access method defined `WITH REFRESH`, and returns an access token and a refresh token.

```go title="Syntax"
tokens, err := session.SignUpWithRefresh(ctx, authData)
```

**Returns:** [`(*Tokens, error)`](/docs/reference/golang/api/types#tokens)

### `.Refresh()` {#refresh}

Exchanges a token pair for a new one, and authenticates this session with it.

```go title="Syntax"
newTokens, err := session.Refresh(ctx, tokens)
```

**Returns:** `(*Tokens, error)`

### `.Revoke()` {#revoke}

Revokes the refresh token of a pair. The session stays signed in.

```go title="Syntax"
err := session.Revoke(ctx, tokens)
```

**Returns:** `error`

### `.Tokens()` {#tokens}

Returns the token pair that this session holds. It returns `nil` when the session holds no pair or when token renewal is off.

```go title="Syntax"
pair := session.Tokens()
```

**Returns:** `*Tokens`

### `.Authenticate()` {#authenticate}

Authenticates this session with a JWT.

```go title="Syntax"
err := session.Authenticate(ctx, token)
```

**Returns:** `error`

### `.Invalidate()` {#invalidate}

Signs this session out.

```go title="Syntax"
err := session.Invalidate(ctx)
```

**Returns:** `error`

### `.Info()` {#info}

Returns the record of the record user signed in to this session.

```go title="Syntax"
info, err := session.Info(ctx)
```

**Returns:** `(map[string]any, error)`

## Session state

### `.Use()` {#use}

Selects the namespace and database of this session.

```go title="Syntax"
err := session.Use(ctx, ns, database)
```

**Returns:** `error`

### `.Let()` {#let}

Sets a variable in this session. The client keeps a copy of the variable, encoded once. It uses this copy to set the variable again when it reconnects, and to copy the variable to a fork.

```go title="Syntax"
err := session.Let(ctx, key, val)
```

**Returns:** `error`

### `.Unset()` {#unset}

Removes a variable from this session.

```go title="Syntax"
err := session.Unset(ctx, key)
```

**Returns:** `error`

### `.Reset()` {#reset}

Returns this session to the state it had when the client attached it. It signs the session out, clears its namespace, database and variables, and kills its live queries. The session stays attached.

```go title="Syntax"
err := session.Reset(ctx)
```

**Returns:** `error`

### `.Version()` {#version}

Returns the version of the server.

```go title="Syntax"
ver, err := session.Version(ctx)
```

**Returns:** [`(*VersionData, error)`](/docs/reference/golang/api/types#versiondata)

## Transactions and live queries

### `.Begin()` {#begin}

Starts an interactive transaction in this session.

```go title="Syntax"
tx, err := session.Begin(ctx)
```

**Returns:** `(*Transaction, error)`. See [`Transaction`](/docs/reference/golang/api/core/transaction). After `.Detach()`, the error is `constants.ErrSessionClosed`.

### `.LiveNotifications()` {#livenotifications}

Returns the notification channel of a live query that this session started with [`Live`](/docs/reference/golang/api/core/db#live).

```go title="Syntax"
ch, err := session.LiveNotifications(liveQueryID)
```

**Returns:** `(chan` [`connection.Notification`](/docs/reference/golang/api/types#notification)`, error)`

### `.CloseLiveNotifications()` {#closelivenotifications}

Closes the notification channel of a live query, without stopping the live query on the server.

```go title="Syntax"
err := session.CloseLiveNotifications(liveQueryID)
```

**Returns:** `error`

---

## Closing a session

### `.Detach()` {#detach}

Removes the session from the server and closes the channels of its live queries. After `.Detach()`, you cannot use the session, and its methods return `constants.ErrSessionClosed`.

```go title="Syntax"
err := session.Detach(ctx)
```

**Returns:** `error`
