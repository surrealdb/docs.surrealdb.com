# Go values {#values}

The Go SDK maps most SurrealDB values onto Go's own types, such as `string`, `bool`, `int64`, `time.Time` and `map[string]any`. Go has no type for some values, such as record IDs, geometry and the SurrealDB 4.0 kinds. For these values, the SDK has types in the `models` package, and this section has a page for each type. This page lists the types and maps each SurrealDB type onto its Go type. For a guide to how values convert, with examples, see [Value types](/docs/reference/golang/concepts/value-types).

```go title="Import"
import "github.com/surrealdb/surrealdb.go/v2/pkg/models"
```

## Value types {#value-types}

- **[CustomDateTime](/docs/reference/golang/api/values/datetime):** `CustomDateTime` wraps `time.Time` for a datetime. The SDK also sends a `time.Time` as a datetime.
- **[CustomDuration](/docs/reference/golang/api/values/duration):** `CustomDuration` wraps `time.Duration` for a duration. The SDK also sends a `time.Duration` as a duration.
- **[Geometry](/docs/reference/golang/api/values/geometry):** `GeometryPoint` and six other types for GeoJSON geometry.
- **[Range](/docs/reference/golang/api/values/range):** `Range` with `BoundIncluded` and `BoundExcluded`, for a span of values or of record IDs.
- **[RecordID](/docs/reference/golang/api/values/record-id):** `RecordID` names one record by its table and ID.
- **[Table](/docs/reference/golang/api/values/table):** `Table` names a table.
- **[UUID](/docs/reference/golang/api/values/uuid):** `UUID` holds a UUID.
- **[Set](/docs/reference/golang/api/values/set):** `Set` holds the distinct values of a set.
- **[Numbers](/docs/reference/golang/api/values/numbers):** `Float16`, `DecimalString` and `BigDecimal`, and the Go types for the sized numbers of SurrealDB 4.0.
- **[Dates, times and intervals](/docs/reference/golang/api/values/temporal):** `PlainDate`, `PlainTime`, `Timestamp` and `Interval`, for the calendar kinds of SurrealDB 4.0.
- **[Regex](/docs/reference/golang/api/values/regex):** `Regex` holds a pattern for the `regex` kind of SurrealDB 4.0.
- **[File](/docs/reference/golang/api/values/file):** `File` points to a file in a bucket.
