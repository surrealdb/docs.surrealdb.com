## `.signin()` {#signin}

Signs this connection in to a specific authentication level and returns the issued tokens.

```swift title="Method Syntax"
let tokens = try await client.signin(credentials)
```

### Arguments

| Argument | Description |
| --- | --- |
| `credentials` (required) | The credentials to authenticate with: one of `.root`, `.namespace`, `.database`, `.accessVariables` or `.accessBearer`. |

### Example usage

The credentials enum describes the level you wish to authenticate at.

```swift
// Root user
let tokens = try await client.signin(.root(username: "root", password: "secret"))

// Namespace user
let tokens = try await client.signin(.namespace(
    namespace: "myapp",
    username: "ns_user",
    password: "secret"
))

// Database user
let tokens = try await client.signin(.database(
    namespace: "myapp",
    database: "mydb",
    username: "db_user",
    password: "secret"
))

// Record access with variables
let tokens = try await client.signin(.accessVariables(
    namespace: "myapp",
    database: "mydb",
    access: "account",
    variables: ["email": .string("user@example.com"), "pass": .string("secret")]
))

// Bearer token access
let tokens = try await client.signin(.accessBearer(
    namespace: "myapp",
    database: "mydb",
    access: "account",
    key: "bearer-token-value"
))
```

## `.signup()` {#signup}

Signs a new record-access user up and returns the issued tokens.

```swift title="Method Syntax"
let tokens = try await client.signup(credentials)
```

### Arguments

| Argument | Description |
| --- | --- |
| `credentials` (required) | The record-access credentials to sign up with, created via `.accessRecord`. |

### Example usage

```swift
let tokens = try await client.signup(.accessRecord(
    namespace: "myapp",
    database: "mydb",
    access: "account",
    variables: ["email": .string("new@example.com"), "pass": .string("secret")]
))
```

## `.authenticate()` {#authenticate}

Authenticates the current connection with a previously issued JWT access token, which resumes a session.

```swift title="Method Syntax"
try await client.authenticate(token)
```

### Arguments

| Argument | Description |
| --- | --- |
| `token` (required) | The JWT access token to authenticate the connection with. |

### Example usage

```swift
try await client.authenticate(tokens.access)
```

Alternatively, provide a token when constructing the client through a `SessionContext`:

```swift
let client = try SurrealHTTPClient(
    endpoint: "http://localhost:8000",
    session: SessionContext(
        namespace: "myapp",
        database: "mydb",
        accessToken: "existing-jwt"
    )
)
```

## `.invalidate()` {#invalidate}

Invalidates the authentication for the current connection, which clears the current authentication state.

```swift title="Method Syntax"
try await client.invalidate()
```

### Example usage

```swift
try await client.invalidate()
```
