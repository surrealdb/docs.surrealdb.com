# Executing queries

The methods below run queries against the database. `query()` runs a query built with the [query DSL](/docs/reference/swift/concepts/query-dsl), and `queryRaw()` runs a raw SurrealQL string with bound parameters. To read and write records with a method for each operation, see [data manipulation](/docs/reference/swift/concepts/data-manipulation).

## `.query()` {#query}

Runs a query built with the query DSL, either a query macro such as `#select` or a `SurrealDSL` builder call.

```swift title="Method Syntax"
try await client.query(query)
```

### Arguments

| Argument | Description |
| --- | --- |
| `query` (required) | A query produced by a query macro or a `SurrealDSL` builder call. |

### Example usage

```swift
// Using a query macro
let selectQuery = #select(Person.self, where: Person.Fields.age > 18, limit: 10)
let people = try await client.query(selectQuery)

// Using the SurrealDSL builder
let query = SurrealDSL.select(Person.self, where: Person.Fields.age >= 21, limit: 50)
let result = try await client.query(query)
```

## `.queryRaw()` {#query-raw}

Executes a raw SurrealQL string with bound parameters and returns one `RPCQueryResult` per statement. Use it for arbitrary SurrealQL that the DSL does not model.

```swift title="Method Syntax"
try await client.queryRaw(sql, bindings: bindings)
```

### Arguments

| Argument | Description |
| --- | --- |
| `sql` (required) | The raw SurrealQL query to execute. |
| `bindings` (optional) | A dictionary of [`SurrealValue`](/docs/reference/swift/concepts/value-types#surrealvalue) parameters referenced in the query. |

### Example usage

```swift
let results: [RPCQueryResult] = try await client.queryRaw(
    "SELECT * FROM person WHERE age > $minAge LIMIT $limit;",
    bindings: [
        "minAge": .int(18),
        "limit": .int(50)
    ]
)

for row in results {
    if row.status == .ok {
        print(row.result)
    }
}
```
