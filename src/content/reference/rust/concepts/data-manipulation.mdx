# Data manipulation

These methods read and write records without writing SurrealQL. Each takes a table name or a record ID, and each has its own page with its arguments, builder methods and examples. To run SurrealQL yourself, see [executing queries](/docs/reference/rust/concepts/executing-queries), and for a live stream of changes to a table, see [live queries](/docs/reference/rust/concepts/live-queries).

| Method | Description |
| --- | --- |
| [`db.select()`](/docs/reference/rust/methods/select) | Selects all records in a table, or a specific record, from the database |
| [`db.create()`](/docs/reference/rust/methods/create) | Creates one or more records in the database |
| [`db.insert()`](/docs/reference/rust/methods/insert) | Adds one record or many to a table, and inserts graph edges through `.relation()` |
| [`db.update()`](/docs/reference/rust/methods/update) | Updates all or specific records in the database |
| [`db.upsert()`](/docs/reference/rust/methods/upsert) | Upserts all records in a table, or a specific record |
| [`db.delete()`](/docs/reference/rust/methods/delete) | Deletes all records in a table, or a specific record, from the database |
