# Executing queries

The Rust SDK runs SurrealQL with `query()`, which takes one or more statements and binds variables to them, and calls a function defined in the database with `run()`. `set()` keeps a parameter on the connection for the queries that follow, and `unset()` removes it. `api()` invokes the endpoints defined with `DEFINE API`.

To read and write records without writing SurrealQL, see [data manipulation](/docs/reference/rust/concepts/data-manipulation). How results are read into Rust types is covered in [value types](/docs/reference/rust/concepts/value-types) and [flexible typing](/docs/reference/rust/concepts/flexible-typing), and [fetching linked records](/docs/reference/rust/concepts/fetch) shows how to follow record links in a query.

| Method | Description |
| --- | --- |
| [`db.query()`](/docs/reference/rust/methods/query) | Runs one or more SurrealQL statements against the database |
| [`db.run()`](/docs/reference/rust/methods/run) | Runs a SurrealQL function |
| [`db.set()`](/docs/reference/rust/methods/set) | Assigns a value as a parameter for this connection |
| [`db.unset()`](/docs/reference/rust/methods/unset) | Removes a parameter from this connection |
| [`db.api()`](/docs/reference/rust/methods/api) | Invokes the endpoints defined with `DEFINE API` on the selected namespace and database |
