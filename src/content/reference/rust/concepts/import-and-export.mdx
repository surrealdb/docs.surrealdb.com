# Import and export

The Rust SDK can write the contents of a database to a file and restore a database from a file. Each method has its own page with its arguments and examples.

| Method | Description |
| --- | --- |
| [`db.export()`](/docs/reference/rust/methods/export) | Dumps the database contents to a file |
| [`db.import()`](/docs/reference/rust/methods/import) | Restores the database from a file |
