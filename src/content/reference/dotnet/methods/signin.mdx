# `.SignIn()` {#signin}

Signs in to a root, namespace, database or scope user.

```csharp title="Method Syntax"
await db.SignIn(credentials)
```

## Example usage

<Tabs syncKey="signin-example">
<TabItem label="Root user">

```csharp
// Sign in as root user
await db.SignIn(new RootAuth { Username = "root",
    Password = "secret" });
```

</TabItem>

<TabItem label="Namespace user">

```csharp
// Sign in using namespace auth
await db.SignIn(
    new NamespaceAuth
    {
        Namespace = "main", 
        Username = "johndoe", 
        Password = "password123" 
    }
);
```

</TabItem>

<TabItem label="Database user">

```csharp
// Sign in using database auth
await db.SignIn(
    new DatabaseAuth
    {
        Namespace = "main", 
        Database = "main", 
        Username = "johndoe", 
        Password = "password123" 
    }
);
```

</TabItem>

<TabItem label="Record Access">

```csharp
// Sign in with Record Access
// Pass every value the access method's SIGNIN clause reads
var authParams = new AuthParams
{
    Namespace = "main",
    Database = "main",
    Access = "user",
    Email = "info@surrealdb.com",
    Pass = "123456"
};

Jwt jwt = await db.SignIn(authParams);

public class AuthParams : ScopeAuth
{
	[CborProperty("email")]
	public string? Email { get; set; }

	[CborProperty("pass")]
	public string? Pass { get; set; }
}
```

</TabItem>

<TabItem label="Scopes">

Before SurrealDB 2.0, record users signed in through a scope rather than an access method. The credentials use the `AuthParams` class from the Record Access tab, with `Scope` set in place of `Access`:

```csharp
// Sign in as a scoped user
var authParams = new AuthParams
{
    Namespace = "main",
    Database = "main",
    Scope = "user",
    Email = "info@surrealdb.com",
    Pass = "123456"
};

Jwt jwt = await db.SignIn(authParams);
```

</TabItem>
</Tabs>

[Handle authentication](/docs/reference/dotnet/core/authentication) shows sign-in as part of the full flow from sign-up to sign-out. You can invalidate the authentication for the current connection using the [`Invalidate()` method](/docs/reference/dotnet/methods/invalidate).
