<Since v="v3.1.0" />

The `surreal db mcp` subcommand starts the built-in [Model Context Protocol](https://modelcontextprotocol.io) server on **stdio**, suitable for Cursor, VS Code, Claude Desktop, and other MCP clients. It opens an embedded datastore at the path you pass (default `memory`) and runs every tool call with owner-level access.

From SurrealDB 4.0, the command writes its log lines to standard error at every log level, so standard output carries only the MCP messages that the client reads.

For HTTP-based clients against a running server, use [`surreal db start`](/docs/reference/cli/db/commands/start) and connect to the **`/mcp`** endpoint instead. See [When to use `surreal db mcp` vs `surreal db start`](/docs/integrate/ai-agents/mcp/embedded#when-to-use-surreal-db-mcp-vs-surreal-db-start) for the comparison, and [Embedded MCP](/docs/integrate/ai-agents/mcp/embedded) for transports, editor setup, and security.

> [!WARNING]
> Stdio MCP is intended for a trusted operator on the same machine. Do not expose this process to untrusted users - there is no per-call HTTP authentication surface to re-bind credentials.

## Capabilities

The capability flags of `surreal db start` apply to the datastore that the command opens, and take the same values. The [capabilities](/docs/learn/security/authorization/capabilities) page describes the targets that each one accepts. Every flag has a `--allow-` and a `--deny-` form that share the row below. A tool call runs as an owner, so these flags limit what a call can reach, such as the functions it calls and the hosts it connects to, and not which user it runs as.

## Usage

```bash
surreal db mcp --ns main --db main memory
```

Optional root credentials apply only when no root user exists yet (same semantics as `surreal db start`):

```bash
surreal db mcp -u root -p secret --ns main --db main memory
```

## Limits

Process-wide MCP limits use the `SURREAL_MCP_*` variables documented in [Environment variables](/docs/reference/cli/db/environment-variables) and on [Embedded MCP](/docs/integrate/ai-agents/mcp/embedded#configuration). For HTTP `/mcp` on a non-loopback hostname, set `SURREAL_MCP_ALLOWED_HOSTS` (or `SURREAL_MCP_ALLOW_ALL_HOSTS` behind a trusted proxy). See those pages for details.
