Convert data written by SurrealDB 1.x into the storage format used by 2.0 and above, using a 2.x version of the database component, which you can run for one command with `surreal +2.6.5 db fix` after `surreal install db@2.6.5`.

> [!IMPORTANT]
> The conversion is only implemented in 2.x binaries. From SurrealDB 3.0.0 the command is still listed, but it exits with `Fix is not implemented` and changes nothing. Run `surreal db fix` with a 2.x binary to move 1.x data to 2.x, then follow [Migrating from 2.x to 3.x](/docs/operate/upgrading/2x-to-3x) to reach 3.x.

## Example usage

To perform a fix from SurrealDB 1.x to 2.x storage, run the `surreal db fix` command in a terminal with the path to the stored data.

```bash
surreal db fix surrealkv://mydatabase.db

surreal db fix rocksdb:somedatabase
```

## Using environment variables

> [!IMPORTANT]
> Most of the flags above have a corresponding [environment variable](/docs/reference/cli/db/environment-variables#command-environment-variables).
> For example, the `--log` flag can be configured with the `SURREAL_LOG` environment variable instead.

When using the `surreal db fix` command, you can also use environment variables to set the values for the command-line flags.

For more on the environment variables available for CLI commands or SurrealDB instances in general, see the [environment variables](/docs/reference/cli/db/environment-variables#command-environment-variables) page.
