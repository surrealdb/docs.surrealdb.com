## Example usage

To display the version of the database component, along with the platform and architecture, run `surreal db version` without any further arguments.

```bash
surreal db version
```

Sample output:

```text
3.3.4 for macos on aarch64
```

If an endpoint is specified, only the version number of the server is displayed.

```bash
surreal db version --endpoint http://localhost:8000
```

Output:

```text
3.3.4
```

## Launcher versions {#launcher-versions}

`surreal version` and `surreal --version` belong to the launcher and do not forward to the database. `surreal version` prints a table with each component, the version that runs, where that version came from, and its path. `surreal --version` prints the launcher version and the version of each component.

```bash
surreal version
```

```text
COMPONENT  VERSION  SOURCE  INSTALLED  PATH
cli        0.1.0    cli                /usr/local/bin/surreal
db         3.3.4    pinned  3.3.4      ~/.surrealdb/components/db/3.3.4/surreal-db
cloud      0.1.0    pinned  0.1.0      ~/.surrealdb/components/cloud/0.1.0/surreal-cloud
```

```bash
surreal --version
```

```text
Surreal CLI 0.1.0
  db      3.3.4
  cloud   0.1.0
```

A component that is not installed has a blank row in the table and reads `not installed` in `surreal --version`. To query a server, or to print the database version alone, use `surreal db version`. See the [launcher reference](/docs/reference/cli/launcher) for the other version commands, including `surreal install`, `surreal use` and `surreal upgrade`.
