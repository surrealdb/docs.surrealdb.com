Print the help information for `surreal db`, or for one of its subcommands.

`surreal db help` and `surreal help` print different things. `surreal db help` is the database's own help, described on this page, because everything after `db` is forwarded to the database. `surreal help` and `surreal --help` are the launcher's help, which lists the components and the commands that manage what is installed. See [Launcher help](#launcher-help).

<Synopsis>
surreal db help [COMMAND]
surreal db <COMMAND> --help
</Synopsis>

## Show the command-line help information

To see the general help information for the database, run `surreal db help` without any further arguments. This command lists the subcommands of `surreal db`.

```bash
surreal db help
```

## Launcher help {#launcher-help}

`surreal help` and `surreal --help` print the launcher's help. It lists the components (`db`, `cloud`), the commands that manage what is installed (`version`, `install`, `upgrade`, `use`, `uninstall`), and the `+VERSION` option that runs another version for one command. Run `surreal <COMPONENT> help`, such as `surreal cloud help`, for the help of a component. The `--no-banner` option, or `SURREAL_CLI_NO_BANNER`, prints the launcher help without the banner. See the [launcher reference](/docs/reference/cli/launcher) for each of these commands.

## Getting help on individual commands

For individual commands, such as `surreal db start` and `surreal db sql`, a help prompt can be displayed by adding the `--help` flag. This flag overrides all other flags, and thus can be added to the end of any command regardless of length.

```bash
surreal db start --help
surreal db start --user root --pass secret --log debug --help
```
