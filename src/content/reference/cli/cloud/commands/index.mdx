# Commands

`surreal cloud` groups its commands by noun. A group on its own prints its own help; the leaf commands below do the work. Every command accepts the [global flags](/docs/reference/cli/cloud/global-flags), and every command except [`token create`](/docs/reference/cli/cloud/commands/token#token-create) accepts `--json`.

| Group | Leaf commands |
| --- | --- |
| [`auth`](/docs/reference/cli/cloud/commands/auth) | `login`, `logout`, `status`, `refresh`, `scopes` |
| [`org`](/docs/reference/cli/cloud/commands/org) | `list`, `get`, `create`, `update`, `archive`, `use`, `roles`, `permissions`, `usage`, `spend`, `plans` |
| [`instance`](/docs/reference/cli/cloud/commands/instance) | `list`, `get`, `create`, `update`, `delete`, `pause`, `resume`, `watch`, `status`, `endpoint`, `token`, `jwks`, `sql`, `import`, `export`, `metrics`, `logs`, `usage`, `estimate`, `capabilities get`, `capabilities set`, `backup list`, `backup create`, `backup policy get`, `backup policy set` |
| [`team`](/docs/reference/cli/cloud/commands/team) | `list`, `get`, `invite`, `update`, `remove` |
| [`invite`](/docs/reference/cli/cloud/commands/invite) | `list`, `create`, `delete` |
| [`token`](/docs/reference/cli/cloud/commands/token) | `list`, `create`, `delete`, `scopes` |
| [`catalog`](/docs/reference/cli/cloud/commands/catalog) | `regions`, `instance-types`, `storage-types`, `instance-versions`, `billing-countries` |
| [`config`](/docs/reference/cli/cloud/commands/config) | `list`, `get`, `set`, `unset`, `path`, `edit` |
| [`context`](/docs/reference/cli/cloud/commands/context) | `show`, `use`, `list` |
| [Other commands](/docs/reference/cli/cloud/commands/misc) | `whoami`, `api`, `open`, `status`, `version`, `completion` |

## Aliases

Plural spellings of the group nouns work, and so do two verb aliases. Nothing else is aliased.

| Alias | Means |
| --- | --- |
| `orgs`, `instances`, `teams`, `invites`, `tokens`, `contexts` | The singular group |
| `ls` | `list` |
| `rm` | `delete` - and `team remove` |
| `doctor` | `status` |

## Reading these pages

Each leaf command gets a usage block, a table of its arguments, a table of its own options, at least one runnable example, and a note on how it refuses.

Usage blocks are notation, not commands: `<NAME>` is a value you must supply, `[NAME]` one you may, `[OPTIONS]` any number of flags, and `...` marks something repeatable. Copy from the examples instead.

Flags shared across many commands are documented once:

- The [global flags](/docs/reference/cli/cloud/global-flags), accepted everywhere.
- The [list presentation flags](/docs/reference/cli/cloud/output-and-exit-codes#list-presentation-flags) - `--columns`, `--wide`, `--no-header`, `--sort`, `--reverse` and `--limit` - carried by every list-shaped command.
- The [wait flags](/docs/reference/cli/cloud/long-running-operations#the-wait-flags) - `--wait`, `--no-wait` and `--wait-timeout` - carried by five `instance` commands.

For queries, imports, exports and running a server, use the [database commands](/docs/reference/cli/db) (`surreal db ...`) instead. See the [overview](/docs/reference/cli/cloud) for where that boundary sits.
