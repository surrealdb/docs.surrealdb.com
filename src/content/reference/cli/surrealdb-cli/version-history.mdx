# Environment variables and flags by version

This page shows which environment variables and command-line flags each SurrealDB release had, from 1.0.0 in September 2023 to 3.3.0. Use it to check whether a setting exists in the version you run, to find what changed between two versions before an upgrade, or to see when a default changed. The [environment variables](/docs/reference/cli/surrealdb-cli/environment-variables) page and the [CLI command](/docs/reference/cli/surrealdb-cli/commands/start) pages describe each setting in the current release.

The table below has three parts:

- **Environment variables and flags**: one row per item, marking the releases that had it, with the newest release on the left. Hover a row for its help text, its exact first and last versions, and the flag or environment variable it pairs with.
- **Release contents**: every environment variable and flag in one release, or the items added, removed or given a new default between two releases.
- **Totals per release**: the number of environment variables and flags in each final release.

## Scope

The lists on this page are read from the SurrealDB source code at each release tag, so they include settings that are not described elsewhere in the documentation. They cover every final release from 1.0.0 onwards, and the alpha, beta and release candidate tags of each release after 1.0.0. The 1.0.0 pre-releases are left out. Dates are the publication dates of the GitHub releases.

- **Environment variables** are the `SURREAL_` names that the server reads, including those that set a command-line flag.
- **Flags and arguments** are those of the `surreal` command and each of its subcommands. A flag declared once on the `surreal` command and accepted by every subcommand, such as `--log` from 2.2.0, counts as present on each subcommand.
- **Defaults** are shown as they are written in the source code. A default that the server works out when it starts, such as a buffer size based on the available memory, is shown as computed at run time.
- **Maintenance releases** of an older line, such as 1.5.6 after the 2.0.0 pre-releases, do not count as removing anything that the newer line added.

Environment variable names that the server builds while it runs, and variables set only in Docker images or deployment files, are not listed.

Across all releases from 1.0.0, 352 environment variables and 246 flags and arguments have existed. Of these, 54 environment variables and 19 flags and arguments are no longer present in 3.3.0. The 2.x releases from 2.3.0 onwards were published alongside the 3.0.0 pre-releases and 3.x, so their dates overlap with the 3.x releases.

From 3.1.0, part of the count is settings read from the configuration map rather than declared one by one: 45 in 3.1.0, 53 in 3.2.0 and 63 in 3.3.0. Each of them can be set with an environment variable whose name is the setting's key in capitals with a `SURREAL_` prefix, such as `SURREAL_ROCKSDB_MEMTABLE_PREFIX_BLOOM_RATIO` for `rocksdb_memtable_prefix_bloom_ratio`.
