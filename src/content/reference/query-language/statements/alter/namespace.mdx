# `ALTER NAMESPACE` statement

<Since v="v3.0.0" />

The `ALTER NAMESPACE` statement can be used to modify the namespace. `ALTER NAMESPACE` is used on the current namespace, which is why a `IF EXISTS` clause does not exist.

## COMPACT

Performs storage compaction on the current namespace keyspace. To compact other resources, use [ALTER SYSTEM](/docs/reference/query-language/statements/alter/system) to compact the entire datastore, [ALTER DATABASE](/docs/reference/query-language/statements/alter/database) to compact the current database keyspace, or [ALTER TABLE](/docs/reference/query-language/statements/alter/table) to compact a specific table keyspace.

The storage engine carries out the compaction. Before SurrealDB 4.0, RocksDB was the only engine that supported compaction requests. No engine in 4.0 supports them, so the clause returns the following error:

```surql
'The storage layer does not support compaction requests.'
```

Before 4.0, a successful compaction on RocksDB returned `NONE`.

```surql
ALTER NAMESPACE COMPACT;
```

```surql title="Output"
NONE
```
