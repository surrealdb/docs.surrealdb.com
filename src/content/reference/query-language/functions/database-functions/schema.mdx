## `schema::table::exists`

The `schema::table::exists` function checks if a table is defined in the current database. It returns `true` for a table created with `DEFINE TABLE`, and `false` for any other name.

```syntax title="API DEFINITION"
schema::table::exists(string) -> bool
```

The following example shows this function, and its output:

```surql
/**[test]

[[test.results]]
error = false

[[test.results]]
value = "true"

[[test.results]]
value = "false"

*/
-- Setup
DEFINE TABLE person;

schema::table::exists('person');
//- true

schema::table::exists('missing');
//- false
```
