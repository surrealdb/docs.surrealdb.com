## `count`

The count function counts the number of times that the function is called. In a [`SELECT`](/docs/reference/query-language/statements/select) that aggregates with [`GROUP BY`](/docs/reference/query-language/clauses/group) or `GROUP ALL`, that call count is the size of each group.

<Since v="v3.3.0" />

When every field in the projection is a bare zero-argument `count()` (optionally aliased), SurrealDB [implies `GROUP ALL`](/docs/reference/query-language/statements/select#bare-count-implies-group-all). Before this change, a bare `count()` returned the constant `1` once per record.

```surql title="API DEFINITION"
count() -> 1
```
If a value is given as the first argument, then this function checks whether a given value is [truthy](/docs/reference/query-language/language-primitives/data-types/values#values-and-truthiness). This is useful for returning the total number of rows which match a certain condition in a [`SELECT`](/docs/reference/query-language/statements/select) with a `GROUP BY` or `GROUP ALL` clause.

```surql title="API DEFINITION"
count(any) -> number
```

If an array is given, this function counts the number of items in the array which are [truthy](/docs/reference/query-language/language-primitives/data-types/values#values-and-truthiness). If, instead, you want to count the total number of items in the given array, then use the [`array::len()`](/docs/reference/query-language/functions/database-functions/array#arraylen) function.

```surql title="API DEFINITION"
count(array) -> number
```
The following example shows this function, and its output:

```surql 
/**[test]

[[test.results]]
value = "1"

*/

count();

-- 1
```

```surql
/**[test]

[[test.results]]
value = "1"

*/

count(true);

-- 1
```

```surql
/**[test]

[[test.results]]
value = "0"

*/

count(10 > 15);

-- 0
```

```surql
/**[test]

[[test.results]]
value = "5"

[[test.results]]
value = "5"

*/

count([ 1, 2, 3, null, 0, false, (15 > 10), rand::uuid() ]);

5
```

The following examples show this function being used in a [`SELECT`](/docs/reference/query-language/statements/select) statement with a `GROUP ALL` clause. From 3.3.0, a projection made only of bare `count()` [implies `GROUP ALL`](/docs/reference/query-language/statements/select#bare-count-implies-group-all); the examples keep the explicit form.

```surql
/**[test]

[[test.results]]
value = "[{ count: 3 }]"

*/

SELECT 
	count() 
FROM [
	{ age: 33 }, 
	{ age: 45 }, 
	{ age: 39 }
] 
GROUP ALL;
```

```surql title="Response"
[
	{ count: 3 }
]
```

```surql
/**[test]

[[test.results]]
value = "[{ count: 2 }]"

*/

SELECT 
	count(age > 35) 
FROM [
	{ age: 33 }, 
	{ age: 45 }, 
	{ age: 39 }
] 
GROUP ALL;
```

```surql title="Response"
[
	{ count: 2 }
]
```

An advanced example of the count function can be seen below:

```surql
/**[test]

[[test.results]]
value = "[{ country: GBR, total: 2 }, { country: USA, total: 2 }]"

*/

SELECT
	country,
	count(age > 30) AS total
FROM [
	{ age: 33, country: 'GBR' },
	{ age: 45, country: 'GBR' },
	{ age: 39, country: 'USA' },
	{ age: 29, country: 'GBR' },
	{ age: 43, country: 'USA' }
]
GROUP BY country;
```

```surql title="Response"
[
	{
		country: 'GBR',
		total: 2
	},
	{
		country: 'USA',
		total: 2
	}
]
```

## Using a `COUNT` index with `count()`

<Since v="v3.0.0" />

A `COUNT` index can be defined to speed up `count()` when used with a `GROUP ALL` clause. This allows `count()` to access a single stored value when it is called instead of iterating over the entire table. From 3.3.0, a bare `count()` projection [implies `GROUP ALL`](/docs/reference/query-language/statements/select#bare-count-implies-group-all); prefer the explicit form in examples and production queries.

```surql
/**[test]

[[test.results]]
value = "[{ id: user:dbb4iogxntigq3m11rdp }]"

[[test.results]]
value = "[{ count: 1 }]"

[[test.results]]
value = "[]"

[[test.results]]
value = "[{ count: 100001 }"

[[test.results]]
value = "NONE"

[[test.results]]
value = "[{ count: 100001 }]"

*/

CREATE user;
-- One record in table, very fast
SELECT count() FROM user GROUP ALL;

-- 10,000 new records,
-- count() takes a bit longer than before
CREATE |user:10000| RETURN NONE;
SELECT count() FROM user GROUP ALL;

-- Add index, wait a moment for it to build
DEFINE INDEX user_count ON user COUNT;
-- count() very performant again
SELECT count() FROM user GROUP ALL;
```
