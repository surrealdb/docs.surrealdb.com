# Functions

Surqlize wraps the SurrealDB [function library](/docs/reference/query-language/functions/database-functions) in two forms. **Type-specific methods** hang off the fields of a record, for example `user.name.uppercase()`. **Standalone functions**, such as `count()` and `math.sum()`, are imported from `surqlize` and take their inputs as arguments. Both can be used in `where()`, `orderBy()`, and `return()`, and each call is typed with the type of its result.

Your editor shows the methods available for each field type. This page covers the common ones and explains the patterns.

## String functions

```ts title="String methods in a filter"
db.select("user").where((user) => user.email.startsWith("admin@"));
db.select("user").where((user) => user.name.endsWith("son"));
db.select("user").where((user) => user.email.contains("@example.com"));
db.select("user").where((user) => user.email.isEmail());
```

```ts title="String methods in a projection"
const rows = await db.select("user").return((user) => ({
    fullName: user.first.join(" ", user.last),
    nameLength: user.name.len(),
    upper: user.name.uppercase(),
    lower: user.email.lowercase(),
    slug: user.name.slug(),
    words: user.name.words(),
    replaced: user.email.replace("@old.com", "@new.com"),
    parts: user.email.split("@"),
}));
```

Other string methods include `capitalize`, `trim`, `repeat`, `slice`, `reverse`, and `matches`, the distance functions (`distanceLevenshtein`, `distanceHamming`, and others), similarity scoring (`similarityJaro`, `similarityFuzzy`, and others), HTML functions (`htmlEncode`, `htmlSanitize`), the validators (`isUrl`, `isDomain`, `isUuid`, `isIp`, and others), and the semantic version functions.

## Array functions

Array fields have membership checks that map to the SurrealQL operators:

```ts title="Array conditions"
db.select("user").where((user) => user.tags.contains("typescript"));
db.select("user").where((user) => user.tags.containsAll(["javascript", "typescript"]));
db.select("user").where((user) => user.tags.containsAny(["rust", "go"]));
db.select("user").where((user) => user.tags.containsNone(["php", "perl"]));
db.select("user").where((user) => user.tags.anyInside(popularTags));
db.select("user").where((user) => user.tags.isEmpty());
```

They also have functions that return values:

```ts title="Array values"
const rows = await db.select("post").return((post) => ({
    title: post.title,
    firstTag: post.tags.first(),
    lastTag: post.tags.last(),
    tagCount: post.tags.len(),
    sorted: post.tags.sort(),
    unique: post.tags.distinct(),
    upper: post.tags.map((tag) => tag.uppercase()),
}));
```

The remaining array methods include the mutating functions (`add`, `append`, `prepend`, `push`, `pop`, `insert`, `remove`, `fill`, `swap`), set-style operations (`combine`, `complement`, `concat`, `difference`, `intersect`, `union`, `transpose`), the boolean functions (`booleanAnd`, `logicalOr`, and others), and search functions (`findIndex`, `filterIndex`, `max`, `min`). Mutating functions in a projection return a new array and do not change the stored record.

## Number and date functions

```ts title="Number methods"
const rows = await db.select("user").return((user) => ({
    rounded: user.age.round(),
    ceiling: user.age.ceil(),
    floored: user.age.floor(),
    squareRoot: user.age.sqrt(),
    squared: user.age.pow(2),
    fixed: user.age.fixed(2),
    clamped: user.age.clamp(0, 100),
}));
```

Number fields also have the trigonometric and logarithmic functions, such as `sin`, `cos`, `tan`, `ln`, `log10`, and `log2`, as well as `abs`, `sign`, and `lerp`.

```ts title="Date methods"
const rows = await db.select("user").return((user) => ({
    year: user.created.year(),
    month: user.created.month(),
    day: user.created.day(),
    weekDay: user.created.wday(),
    unix: user.created.unix(),
    formatted: user.created.format("%Y-%m-%d"),
}));
```

Date fields also have `hour`, `minute`, `second`, `week`, `yday`, `millis`, `isLeapYear`, and the rounding functions `timeCeil`, `timeFloor`, and `timeRound`.

## Option functions

A field of type `t.option()` has helpers for the case where the value is missing.

| Method | Result |
| ------ | ------ |
| `unwrapOr(fallback)` | The value, or the fallback when it is `NONE`. The result is not optional. |
| `isNone()`, `isSome()` | Whether the value is absent or present. |
| `isSomeAnd(callback)` | Whether the value is present and the callback's condition holds. |
| `unwrap()` | Treats the value as its inner type, so that you can call the inner type's methods. SurrealDB handles `NONE` itself, so the query is unchanged. |

```ts title="Work with optional fields"
const rows = await db.select("user").return((user) => ({
    name: user.name,
    bio: user.bio.unwrapOr("No bio"),
    hasBio: user.bio.isSome(),
}));

const withLongBio = await db
    .select("user")
    .where((user) => user.bio.isSomeAnd((bio) => bio.len().gt(100)));
```

## Record functions

A record link can run a nested query with `.select()`, as described in [querying](/docs/reference/javascript/libraries/surqlize/querying#nested-selects). Record links can also start [graph traversals](/docs/reference/javascript/libraries/surqlize/edges-and-graph).

## Standalone functions

Standalone functions are not called on a field. A function that takes values reads its query context from its first value, so you pass fields of the current record as arguments. A function without arguments, or a constant, needs a field or record from the callback to supply that context.

```ts title="Standalone functions"
import { count, crypto, math, parse, time } from "surqlize";

const stats = await db
    .select("user")
    .groupAll()
    .return((user) => ({ total: count(user) }));

const rows = await db.select("user").return((user) => ({
    now: time.now(user),
    emailHash: crypto.sha256(user.email),
    emailDomain: parse.emailHost(user.email),
    pi: math.pi(user),
}));
```

`time.now(user)` and `math.pi(user)` take `user` only to supply the context. `count(user)` counts the records of a [grouped](/docs/reference/javascript/libraries/surqlize/querying#splitting-and-grouping) select.

The standalone function families are `count`, `math`, `time`, `crypto`, `rand`, `duration`, `type_`, `encoding`, `geo`, `http`, `meta`, `object`, `parse`, `search`, `session`, `set_`, `sleep`, `value`, `vector`, `bytes`, and `not`. The names `type_` and `set_` carry a trailing underscore. Surqlize also exports the `and()` and `or()` condition combiners described in [querying](/docs/reference/javascript/libraries/surqlize/querying#combining-conditions).

## Literal values in expressions

`db.value()` wraps a JavaScript value so that it can be passed to a function or used at the start of a traversal. A `RecordId` keeps its table type.

```ts title="Wrap a value"
const queryVector = db.value([0.1, 0.2, 0.3]);
const startingPoint = db.value(new RecordId("person", "tobie")).out("knows");
```
