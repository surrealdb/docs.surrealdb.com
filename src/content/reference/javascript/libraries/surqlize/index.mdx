# Surqlize (ORM)

[Surqlize](https://github.com/surrealdb/surqlize) is a type-safe object-relational mapper for SurrealDB in TypeScript. You describe your tables and edges in code, then build queries with a fluent API instead of writing SurrealQL strings. It is built on top of the [JavaScript SDK](/docs/reference/javascript) and uses the SDK to connect to the database and send queries.

TypeScript infers the type of every query result from your schema, so there is no code generation step. Each query compiles to SurrealQL with the values sent as bound parameters.

```ts title="Define a schema and query it"
import { Surreal } from "surrealdb";
import { orm, table, t } from "surqlize";

const user = table("user", {
    name: t.string(),
    email: t.string(),
    age: t.number(),
});

const surreal = new Surreal();
await surreal.connect("ws://localhost:8000", {
    namespace: "app",
    database: "app",
    authentication: { username: "root", password: "secret" },
});

const db = orm(surreal, user);

await db.create("user").content({ name: "Ada", email: "ada@example.com", age: 36 });

const adults = await db
    .select("user")
    .where((user) => user.age.gte(18))
    .return((user) => ({ name: user.name, email: user.email }));
// adults: { name: string; email: string }[]
```

## Key ideas

- **Schemas live in code.** `table()` and `edge()` describe your records with the `t.*` type builders. Surqlize does not create tables or fields in the database for you, apart from [computed fields](/docs/reference/javascript/libraries/surqlize/schema#computed-fields) on request.
- **Queries are immutable builders.** Every chained method returns a new query, so a partly built query can be reused. Awaiting a query runs it.
- **Results are typed and parsed.** The result of a query is checked against the schema as it arrives, and a mismatch throws instead of passing bad data on.
- **Graph traversal is part of the query builder.** Edges are typed, and traversal steps only accept edges that connect to the current table.
- **Runtime validation is opt-in.** Data you write can be checked against the schema before it is sent. See [runtime validation](/docs/reference/javascript/libraries/surqlize/validation).
