# Core classes

The core classes cover connecting to SurrealDB, scoping work to a session or a transaction, and executing queries. Every other part of the SDK is reached through one of these.

## Classes

- [**Surreal**](/docs/reference/javascript/api/core/surreal) - The main entry point for connecting to and interacting with a SurrealDB instance.
- [**SurrealSession**](/docs/reference/javascript/api/core/surreal-session) - Session-scoped context with authentication and query execution.
- [**SurrealQueryable**](/docs/reference/javascript/api/core/surreal-queryable) - The query execution methods shared by sessions and transactions.
- [**SurrealTransaction**](/docs/reference/javascript/api/core/surreal-transaction) - Atomic transaction support for executing multiple queries.
- [**SurrealApi**](/docs/reference/javascript/api/core/surreal-api) - Methods for invoking user-defined API endpoints.
