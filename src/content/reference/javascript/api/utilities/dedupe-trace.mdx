# `dedupeTrace()` {#dedupetrace}

The `dedupeTrace()` function removes the entries of a [query trace](/docs/reference/javascript/concepts/tracing-queries) that repeat an earlier entry, and keeps the first copy of each. A statement can report the same edge, reference or link on more than one frame, and `.responses()` and `.statements()` join the frames as they were sent.

**Import:**
```ts
import { dedupeTrace } from 'surrealdb';
```

**Source:** [utils/dedupe-trace.ts](https://github.com/surrealdb/surrealdb.js/blob/main/packages/sdk/src/utils/dedupe-trace.ts)

## Function signature

```ts
function dedupeTrace(trace: QueryTrace): QueryTrace
```

### Returns
[`QueryTrace`](/docs/reference/javascript/api/types/#querytrace) - A trace that holds each entry once

Entries are identified by their record ids, and a link also by its field. Subscriptions are identified by their id. Variables are keyed by name, so they cannot repeat.

## Example

```ts
const [response] = await db
    .query('SELECT ->tagged->tag FROM post')
    .trace('relations')
    .responses();

if (response.success && response.trace) {
    const unique = dedupeTrace(response.trace);
}
```
