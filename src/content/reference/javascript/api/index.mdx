# API reference

Reference documentation for every public class, type, and helper in the JavaScript SDK. For task-oriented guidance, see the [concepts](/docs/reference/javascript/concepts/connecting-to-surrealdb) pages.

## Sections

- [**Core classes**](/docs/reference/javascript/api/core) - Connecting, sessions, transactions, and query execution.
- [**Query builders**](/docs/reference/javascript/api/queries) - The chainable builders returned by each query method.
- [**Data types**](/docs/reference/javascript/api/values) - Classes for SurrealDB-specific values such as `RecordId` and `Duration`.
- [**Utilities**](/docs/reference/javascript/api/utilities/surql) - Helpers for building parameterised queries and comparing values.
- [**Errors**](/docs/reference/javascript/api/errors) - Error classes raised by the SDK.
- [**TypeScript types**](/docs/reference/javascript/api/types) - Type definitions and interfaces used throughout the SDK.
