# `AsyncSurrealSession` / `BlockingSurrealSession` {#surreal-session}

A session object runs requests in one session on the server, with its own namespace, database, variables and sign-in, over the WebSocket connection that created it. This page lists the properties and methods of `BlockingSurrealSession`, which a blocking connection returns, and `AsyncSurrealSession`, which an asynchronous connection returns. See [Multiple sessions](/docs/reference/python/concepts/multiple-sessions) for how to use them.

Sessions need a WebSocket connection (`ws://` or `wss://`) and SurrealDB 3.0 or later. On an HTTP or embedded connection, `new_session()` raises `UnsupportedFeatureError`. Against SurrealDB 2.x, it raises `UnavailableFeatureError`.

**Source:** [`async_ws.py`](https://github.com/surrealdb/surrealdb.py/blob/main/src/surrealdb/connections/async_ws.py) · [`blocking_ws.py`](https://github.com/surrealdb/surrealdb.py/blob/main/src/surrealdb/connections/blocking_ws.py)

## Creating a session {#creating}

```python title="Syntax"
session = db.new_session()
```

**Returns:** a `BlockingSurrealSession` on a blocking connection, or an `AsyncSurrealSession` on an asynchronous connection

[`new_session()`](/docs/reference/python/api/core/surreal#new-session) starts a session that is signed in as the user of the connection, with no namespace, database or variables. Two other methods start a session as a copy of an existing one: [`fork()`](#fork) on a session, and [`fork_session()`](/docs/reference/python/api/core/surreal#fork-session) on the connection.

<Tabs syncKey="python-sync-async">
	<TabItem value="sync" label="Synchronous" default>
		```python
		from surrealdb import Surreal

		db = Surreal("ws://localhost:8000")
		db.connect()
		db.signin({"username": "root", "password": "secret"})

		session = db.new_session()
		session.use("surrealdb", "reports")
		```
	</TabItem>
	<TabItem value="async" label="Asynchronous">
		```python
		from surrealdb import AsyncSurreal

		db = AsyncSurreal("ws://localhost:8000")
		await db.connect()
		await db.signin({"username": "root", "password": "secret"})

		session = await db.new_session()
		await session.use("surrealdb", "reports")
		```
	</TabItem>
</Tabs>

## Properties

### `.id` {#id}

The `UUID` of the session on the server. [`db.sessions()`](/docs/reference/python/api/core/surreal#sessions) lists the same ids, and the connection methods that take a `session_id` keyword accept it.

### `.server_version` {#server-version}

The version that the server reported when the connection opened, such as `"4.0.0"`. It is the same value as the [`server_version`](/docs/reference/python/api/core/surreal#server-version) of the connection.

## Session methods

### `.begin_transaction()` {#begin-transaction}

Begin a transaction in the session. Needs SurrealDB 3.0 or later.

```python title="Syntax"
session.begin_transaction()
```

**Returns:** a [`BlockingSurrealTransaction`](/docs/reference/python/api/core/surreal-transaction), or an `AsyncSurrealTransaction` on an asynchronous session

The transaction runs with the namespace, database and sign-in of the session. It is a context manager that commits when the block finishes, and cancels when the block raises an exception:

```python
from surrealdb import RecordID

with session.begin_transaction() as txn:
    txn.create(RecordID("person", "tobie"), {"name": "Tobie"})
    txn.create(RecordID("person", "jaime"), {"name": "Jaime"})
```

On an asynchronous session, write `async with await session.begin_transaction() as txn:`.

### `.fork()` {#fork}

Start a new session as a copy of this one. Needs SurrealDB 3.0 or later.

```python title="Syntax"
session.fork()
```

**Returns:** a new session of the same class

The copy gets the namespace, database, variables and access token of the session. It does not get the refresh token, because the server accepts a refresh token only once. The two sessions are independent from then on.

```python
copy = session.fork()
print(copy.query("RETURN session::db()").first())
```

```text title="Output"
reports
```

On an asynchronous session, write `copy = await session.fork()`.

### `.close_session()` {#close-session}

End the session on the server.

```python title="Syntax"
session.close_session()
```

**Returns:** `None`

The connection and its other sessions stay open. A request on the session object after `close_session()` raises `NotFoundError`. Sessions are not context managers, so to end a session also when your code raises an exception, call `close_session()` in a `finally` block, as the example below does.

On an asynchronous session, write `await session.close_session()`.

## Complete example

The example below runs a transaction in a session that uses another database, and closes the session at the end:

<Tabs syncKey="python-sync-async">
	<TabItem value="sync" label="Synchronous" default>
		```python
		from surrealdb import RecordID, Surreal

		with Surreal("ws://localhost:8000") as db:
		    db.signin({"username": "root", "password": "secret"})
		    db.use("surrealdb", "docs")

		    reports = db.new_session()
		    try:
		        reports.use("surrealdb", "reports")

		        with reports.begin_transaction() as txn:
		            for name in ("Tobie", "Jaime"):
		                record = RecordID("person", name.lower())
		                txn.create(record, {"name": name})

		        query = "SELECT VALUE name FROM person ORDER BY name"
		        print(reports.query(query).first())
		        print(db.query("RETURN session::db()").first())
		        print(reports.id in db.sessions())
		    finally:
		        reports.close_session()
		```
	</TabItem>
	<TabItem value="async" label="Asynchronous">
		```python
		import asyncio

		from surrealdb import AsyncSurreal, RecordID


		async def main():
		    async with AsyncSurreal("ws://localhost:8000") as db:
		        await db.signin({"username": "root", "password": "secret"})
		        await db.use("surrealdb", "docs")

		        reports = await db.new_session()
		        try:
		            await reports.use("surrealdb", "reports")

		            async with await reports.begin_transaction() as txn:
		                for name in ("Tobie", "Jaime"):
		                    record = RecordID("person", name.lower())
		                    await txn.create(record, {"name": name})

		            query = "SELECT VALUE name FROM person ORDER BY name"
		            print(await reports.query(query).first())
		            print(await db.query("RETURN session::db()").first())
		            print(reports.id in await db.sessions())
		        finally:
		            await reports.close_session()


		asyncio.run(main())
		```
	</TabItem>
</Tabs>

```text title="Output"
['Jaime', 'Tobie']
docs
True
```
