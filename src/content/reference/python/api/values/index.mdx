# Python values {#values}

The Python SDK has classes for the SurrealDB values that Python has no type for, such as record IDs, durations and geometry. This section has a page for each class. This page lists those pages, maps each Python type to its SurrealDB type, and shows the `Value` union that the SDK uses for any value. For a guide to how values convert, with examples, see [Value types](/docs/reference/python/concepts/value-types).

## Value classes {#value-classes}

- **[RecordID](/docs/reference/python/api/values/record-id):** `RecordID` names one record by its table and ID, and `StringRecordId` names one as SurrealQL text.
- **[Table](/docs/reference/python/api/values/table):** `Table` names a table, as a CRUD target or a query variable.
- **[Null](/docs/reference/python/api/values/null):** `Null` is the SurrealDB `NULL`, which is a different value from `None`.
- **[Datetime](/docs/reference/python/api/values/datetime):** Every datetime reads back as a `PreciseDatetime`, and `Datetime` sends ISO 8601 text.
- **[Duration](/docs/reference/python/api/values/duration):** `Duration` holds a length of time in nanoseconds.
- **[SurrealSet](/docs/reference/python/api/values/set):** Every set reads back as a `SurrealSet`, which the SDK writes back as a set.
- **[Range](/docs/reference/python/api/values/range):** `Range` with `BoundIncluded` and `BoundExcluded` holds a span of values or of record IDs.
- **[Geometry](/docs/reference/python/api/values/geometry):** `GeometryPoint` and six other classes hold geospatial data.
- **[File](/docs/reference/python/api/values/file):** `File` refers to a file in a bucket, and `FileMetadata` describes a stored file.
- **[Sized numbers and BigDecimal](/docs/reference/python/api/values/numbers):** `I8` to `U64`, `F16`, `F32` and `BigDecimal` hold the SurrealDB 4.0 number types.
- **[Dates, times and intervals](/docs/reference/python/api/values/temporal):** `PlainDate`, `PlainTime`, `Timestamp` and `Interval` hold the SurrealDB 4.0 calendar types.
- **[Regex](/docs/reference/python/api/values/regex):** `Regex` holds a pattern for the SurrealDB 4.0 `regex` type.

The SDK sends the SurrealDB 4.0 types as their own types only over `cbor.2`, the format that SurrealDB 4.0 servers speak. Against an earlier server, it sends the nearest type that the server has, and the page for each class says what that is. A `datetime.timedelta` and a compiled `re.Pattern` cannot be sent, and raise `TypeError`.

## The `Value` type {#value}

`Value` is the union of the values that the SDK sends and reads back, and methods use it to annotate data and results. The [Python types](/docs/reference/python/api/types#value) page explains it in full.

```python title="Type definition"
Value = (
    str | int | float | bool | None | NullType
    | bytes | UUID | Decimal
    | Table | Range | RecordID | StringRecordId | File
    | Duration | Datetime
    | BigDecimal | PlainDate | PlainTime | Timestamp | Interval | Regex
    | date | time
    | GeometryPoint | GeometryLine | GeometryPolygon
    | GeometryMultiPoint | GeometryMultiLine | GeometryMultiPolygon
    | GeometryCollection
    | SurrealSet | set[Any] | frozenset[Any]
    | dict[str, "Value"] | list["Value"]
)
```

## `RecordIdType` {#recordidtype}

`RecordIdType` is the union that CRUD methods accept as a target. A `str` in it is always a table name. Import it from `surrealdb.data.types.record_id`; the [RecordID](/docs/reference/python/api/values/record-id#recordidtype) page has the details.

```python title="Type definition"
RecordIdType = str | RecordID | StringRecordId | Table
```

## `Tokens` {#tokens}

`Tokens` is the frozen dataclass that `signin()` and `signup()` return, with an `access` token and an optional `refresh` token. It is documented with the other dataclasses on the [Python types](/docs/reference/python/api/types#tokens) page.
