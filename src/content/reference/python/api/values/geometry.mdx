# Geometry types {#geometry}

SurrealDB stores geospatial data in the `geometry` type, which follows GeoJSON. The Python SDK has one class for each of the seven kinds of geometry, and each class maps to its SurrealDB kind in both directions. This page documents the constructors, which take their parts as separate arguments, and how geometry reads back.

```python title="Import"
from surrealdb import (
    GeometryCollection,
    GeometryLine,
    GeometryMultiLine,
    GeometryMultiPoint,
    GeometryMultiPolygon,
    GeometryPoint,
    GeometryPolygon,
)
```

**Source:** [geometry.py](https://github.com/surrealdb/surrealdb.py/blob/main/src/surrealdb/data/types/geometry.py)

---

## Classes {#classes}

| Class | SurrealDB type | Constructor |
|---|---|---|
| [`GeometryPoint`](#geometrypoint) | `geometry<point>` | `GeometryPoint(longitude, latitude)` |
| [`GeometryLine`](#geometryline) | `geometry<line>` | `GeometryLine(point1, point2, *more_points)` |
| [`GeometryPolygon`](#geometrypolygon) | `geometry<polygon>` | `GeometryPolygon(exterior_ring, *interior_rings)` |
| [`GeometryMultiPoint`](#geometrymultipoint) | `geometry<multipoint>` | `GeometryMultiPoint(*points)` |
| [`GeometryMultiLine`](#geometrymultiline) | `geometry<multiline>` | `GeometryMultiLine(*lines)` |
| [`GeometryMultiPolygon`](#geometrymultipolygon) | `geometry<multipolygon>` | `GeometryMultiPolygon(*polygons)` |
| [`GeometryCollection`](#geometrycollection) | `geometry<collection>` | `GeometryCollection(*geometries)` |

Every constructor takes its parts as separate positional arguments. `GeometryLine(start, end)` is correct, and `GeometryLine([start, end])` raises `TypeError`. To build a geometry from a list, unpack the list: `GeometryLine(*points)`.

A point gives its longitude first and its latitude second, the same order as GeoJSON.

The `Geometry` base class is also exported. Use it in an `isinstance()` check for the first six classes. `GeometryCollection` is not a subclass of `Geometry`, and a `Geometry` itself cannot be sent.

## `GeometryPoint` {#geometrypoint}

A `GeometryPoint` is a single position.

```python title="Syntax"
GeometryPoint(longitude, latitude)
```

    <thead>
        <tr>
            <th>Parameter</th>
            <th>Type</th>

    </thead>
    <tbody>
        <tr>
            <td><code>longitude</code> <Label label="required" /></td>
            <td><code>float</code></td>
            <td>The longitude, or the x coordinate.</td>
        </tr>
        <tr>
            <td><code>latitude</code> <Label label="required" /></td>
            <td><code>float</code></td>
            <td>The latitude, or the y coordinate.</td>
        </tr>
    </tbody>
</table>

The point keeps the two values as its `longitude` and `latitude` attributes.

```python
london = GeometryPoint(-0.1278, 51.5074)
print(london.longitude, london.latitude)
```

```text title="Output"
-0.1278 51.5074
```

## `GeometryLine` {#geometryline}

A `GeometryLine` is a line through two or more points, in order.

```python title="Syntax"
GeometryLine(point1, point2, *more_points)
```

<table>
    <thead>
        <tr>
            <th>Parameter</th>
            <th>Type</th>
            <th>Description</th>
        </tr>
    </thead>
    <tbody>
        <tr>
            <td><code>point1</code>, <code>point2</code> <Label label="required" /></td>
            <td><code>GeometryPoint</code></td>
            <td>The first two points of the line.</td>
        </tr>
        <tr>
            <td><code>*more_points</code> <Label label="optional" /></td>
            <td><code>GeometryPoint</code></td>
            <td>Further points, in order.</td>
        </tr>
    </tbody>
</table>

The points are in the `geometry_points` attribute, a `list[GeometryPoint]`.

```python
route = GeometryLine(
    GeometryPoint(-0.1278, 51.5074),
    GeometryPoint(-1.8904, 52.4862),
    GeometryPoint(-3.1883, 55.9533),
)
print(len(route.geometry_points))
```

```text title="Output"
3
```

## `GeometryPolygon` {#geometrypolygon}

A `GeometryPolygon` is a polygon made of one outer ring and any number of inner rings, which are holes. A ring is a `GeometryLine` that is closed: its first and last points are equal, and it has at least four points.

```python title="Syntax"
GeometryPolygon(exterior_ring, *interior_rings)
```

<table>
    <thead>
        <tr>
            <th>Parameter</th>
            <th>Type</th>
            <th>Description</th>
        </tr>
    </thead>
    <tbody>
        <tr>
            <td><code>exterior_ring</code> <Label label="required" /></td>
            <td><code>GeometryLine</code></td>
            <td>The outer boundary.</td>
        </tr>
        <tr>
            <td><code>*interior_rings</code> <Label label="optional" /></td>
            <td><code>GeometryLine</code></td>
            <td>Holes inside the outer boundary.</td>
        </tr>
    </tbody>
</table>

The rings are in the `geometry_lines` attribute, outer ring first. A ring that is not closed, or that has fewer than four points, raises `InvalidGeometryError`.

```python
outer = GeometryLine(
    GeometryPoint(0, 0),
    GeometryPoint(4, 0),
    GeometryPoint(4, 4),
    GeometryPoint(0, 4),
    GeometryPoint(0, 0),
)
hole = GeometryLine(
    GeometryPoint(1, 1),
    GeometryPoint(2, 1),
    GeometryPoint(2, 2),
    GeometryPoint(1, 2),
    GeometryPoint(1, 1),
)
area = GeometryPolygon(outer, hole)
print(len(area.geometry_lines))
```

```text title="Output"
2
```

## `GeometryMultiPoint` {#geometrymultipoint}

A `GeometryMultiPoint` is a group of points.

```python title="Syntax"
GeometryMultiPoint(*points)
```

The points are in the `geometry_points` attribute.

```python
stops = GeometryMultiPoint(
    GeometryPoint(-0.1278, 51.5074),
    GeometryPoint(-3.1883, 55.9533),
)
print(len(stops.geometry_points))
```

```text title="Output"
2
```

---

## `GeometryMultiLine` {#geometrymultiline}

A `GeometryMultiLine` is a group of lines.

```python title="Syntax"
GeometryMultiLine(*lines)
```

The lines are in the `geometry_lines` attribute.

```python
tracks = GeometryMultiLine(
    GeometryLine(GeometryPoint(0, 0), GeometryPoint(1, 1)),
    GeometryLine(GeometryPoint(2, 2), GeometryPoint(3, 3)),
)
print(len(tracks.geometry_lines))
```

```text title="Output"
2
```

---

## `GeometryMultiPolygon` {#geometrymultipolygon}

A `GeometryMultiPolygon` is a group of polygons.

```python title="Syntax"
GeometryMultiPolygon(*polygons)
```

The polygons are in the `geometry_polygons` attribute.

```python
square = GeometryLine(
    GeometryPoint(0, 0),
    GeometryPoint(1, 0),
    GeometryPoint(1, 1),
    GeometryPoint(0, 1),
    GeometryPoint(0, 0),
)
farms = GeometryMultiPolygon(GeometryPolygon(square))
print(len(farms.geometry_polygons))
```

```text title="Output"
1
```

---

## `GeometryCollection` {#geometrycollection}

A `GeometryCollection` is a group of geometries of any kind, mixed.

```python title="Syntax"
GeometryCollection(*geometries)
```

The geometries are in the `geometries` attribute.

```python
site = GeometryCollection(
    GeometryPoint(-0.1278, 51.5074),
    GeometryLine(GeometryPoint(0, 0), GeometryPoint(1, 1)),
)
print(len(site.geometries))
```

```text title="Output"
2
```

## Common methods {#methods}

`str()` renders a geometry as a SurrealQL literal, for logs and debugging. To use a geometry in a query, pass it as a variable instead.

```python
print(GeometryPoint(-0.1278, 51.5074))
print(GeometryLine(GeometryPoint(0, 0), GeometryPoint(1, 1)))
```

```text title="Output"
(-0.1278, 51.5074)
{ type: 'LineString', coordinates: [[0, 0], [1, 1]] }
```

Every class except `GeometryCollection` also has these methods:

| Method | Returns | Description |
|---|---|---|
| `get_coordinates()` | `tuple` or `list` | The GeoJSON coordinates, with each position as a `(longitude, latitude)` tuple. |
| `parse_coordinates(coordinates)` | the same class | Static method. Builds a geometry from GeoJSON coordinates. |

Two geometries of the same class are equal when their coordinates are equal, and every geometry is hashable.

## Usage {#usage}

Store a geometry as a field value, and pass one as a query variable to use it with the [geo functions](/docs/reference/query-language/functions/database-functions/geo).

```python
from surrealdb import GeometryPoint, RecordID, Surreal

with Surreal("ws://localhost:8000") as db:
    db.signin({"username": "root", "password": "secret"})
    db.use("surrealdb", "docs")

    db.create(RecordID("place", "london"), {
        "location": GeometryPoint(-0.1278, 51.5074),
    })
    db.create(RecordID("place", "edinburgh"), {
        "location": GeometryPoint(-3.1883, 55.9533),
    })

    sql = """
        SELECT VALUE id FROM place
        WHERE geo::distance(location, $here) < 50000
    """
    here = GeometryPoint(-0.1180, 51.5099)
    print(db.query(sql, {"here": here}).first())
```

```python title="Output"
[RecordID(table_name=place, record_id='london')]
```

A geometry reads back as the same class. The coordinates of a point read back as `float` values, so `GeometryPoint(1, 2)` reads back as `GeometryPoint(longitude=1.0, latitude=2.0)`, which is still equal to the point that was sent.
