# `Duration` {#duration}

A `Duration` holds a length of time as a whole number of nanoseconds, and maps to the SurrealDB `duration` type in both directions. This page documents how to make a `Duration`, how to read it in other units, and how to convert a `datetime.timedelta`, which the SDK does not send.

```python title="Import"
from surrealdb import Duration
```

**Source:** [duration.py](https://github.com/surrealdb/surrealdb.py/blob/main/src/surrealdb/data/types/duration.py)

---

## `Duration.parse()` {#parse}

`Duration.parse()` builds a `Duration` from SurrealQL duration text, or from a whole number of seconds.

```python title="Syntax"
Duration.parse(value, nanoseconds=0)
```

<table>
    <thead>
        <tr>
            <th>Parameter</th>
            <th>Type</th>
            <th>Description</th>
        </tr>
    </thead>
    <tbody>
        <tr>
            <td><code>value</code> <Label label="required" /></td>
            <td><code>str | int</code></td>
            <td>Text made of one or more parts, each a whole number and a unit, such as <code>"1h30m"</code>. An <code>int</code> is a number of seconds.</td>
        </tr>
        <tr>
            <td><code>nanoseconds</code> <Label label="optional" /></td>
            <td><code>int</code></td>
            <td>Nanoseconds to add to the result. Defaults to <code>0</code>.</td>
        </tr>
    </tbody>
</table>

**Returns:** `Duration`

The units are the ones SurrealQL uses, in lower case:

| Unit | Meaning |
|---|---|
| `ns` | Nanoseconds |
| `us` or `µs` | Microseconds |
| `ms` | Milliseconds |
| `s` | Seconds |
| `m` | Minutes |
| `h` | Hours |
| `d` | Days |
| `w` | Weeks |
| `y` | Years of 365 days |

`parse()` accepts the same text as the server. Spaces around the text are ignored, but text with a fraction (`"1.5s"`), a sign (`"-1s"`), an exponent (`"1e3s"`) or an upper-case unit (`"1H"`) raises `InvalidDurationError`, and so does a negative `int`.

```python
print(Duration.parse("1h30m").minutes)
print(Duration.parse("500ms").milliseconds)
print(Duration.parse("2d12h").hours)
print(Duration.parse(90))
print(Duration.parse(90, nanoseconds=500).nanoseconds)
```

```text title="Output"
90
500
60
1m30s
90000000500
```

```python
Duration.parse("1.5s")
```

```text title="Error output"
surrealdb.errors.InvalidDurationError: Invalid duration format: 1.5s
```

## Properties {#properties}

Each unit property gives the number of whole units in the duration as an `int`, rounded down. `Duration.parse("1h30m").hours` is `1`, not `1.5`.

| Property | Type | Description |
|---|---|---|
| `nanoseconds` | `int` | The whole duration in nanoseconds, the same value as `elapsed`. |
| `microseconds` | `int` | Whole microseconds. |
| `milliseconds` | `int` | Whole milliseconds. |
| `seconds` | `int` | Whole seconds. |
| `minutes` | `int` | Whole minutes. |
| `hours` | `int` | Whole hours. |
| `days` | `int` | Whole days. |
| `weeks` | `int` | Whole weeks. |
| `years` | `int` | Whole years of 365 days. |

For a fraction of a unit, divide `nanoseconds` by the length of the unit in nanoseconds.

```python
length = Duration.parse("2h30m")
print(length.hours, length.minutes, length.seconds)
print(length.nanoseconds / 3_600_000_000_000)
```

```text title="Output"
2 150 9000
2.5
```

## Methods {#methods}

### `to_string()` {#to-string}

`to_string()` returns the duration as SurrealQL duration text, with the largest units first. `str(duration)` gives the same text, and a zero duration gives `0ns`.

```python title="Syntax"
duration.to_string()
```

**Returns:** `str`

```python
print(Duration.parse("90m").to_string())
print(Duration(1_500_000_000).to_string())
print(Duration().to_string())
```

```text title="Output"
1h30m
1s500ms
0ns
```

### `to_compact()` {#to-compact}

`to_compact()` returns a list that holds the number of whole seconds. The part of a second is not included.

```python title="Syntax"
duration.to_compact()
```

**Returns:** `list[int]`

```python
print(Duration(1_500_000_000).to_compact())
```

```text title="Output"
[1]
```

### `get_seconds_and_nano()` {#get-seconds-and-nano}

`get_seconds_and_nano()` returns the whole seconds and the nanoseconds left over, which are the two parts that SurrealDB stores.

```python title="Syntax"
duration.get_seconds_and_nano()
```

**Returns:** `tuple[int, int]`

```python
print(Duration(1_500_000_000).get_seconds_and_nano())
```

```text title="Output"
(1, 500000000)
```

## Equality and hashing {#eq}

Two `Duration` values are equal when they hold the same number of nanoseconds, however they were written. A `Duration` is hashable, so it can be a `dict` key or a member of a `set`. `repr()` shows the nanoseconds.

```python
print(Duration.parse("90m") == Duration.parse("1h30m"))
print(repr(Duration.parse("90m")))
```

```text title="Output"
True
Duration(elapsed=5400000000000)
```

## Converting a timedelta {#timedelta}

The SDK does not send a `datetime.timedelta`, and raises `TypeError` for one. Convert it to a `Duration` first. Integer division by one microsecond keeps the value exact:

```python
import datetime as dt
from surrealdb import Duration

timeout = dt.timedelta(minutes=1, seconds=30)
length = Duration((timeout // dt.timedelta(microseconds=1)) * 1000)
print(length)
```

```text title="Output"
1m30s
```

To go the other way, use `dt.timedelta(microseconds=length.nanoseconds // 1000)`. A `timedelta` holds microseconds, so the nanoseconds below one microsecond are dropped.

## Usage {#usage}

A `Duration` can be a field value or a query variable, and a `duration` that the server returns reads back as a `Duration`.

```python
from surrealdb import Duration, RecordID, Surreal

with Surreal("ws://localhost:8000") as db:
    db.signin({"username": "root", "password": "secret"})
    db.use("surrealdb", "docs")

    db.create(RecordID("account", "tobie"), {
        "session_timeout": Duration.parse("30m"),
    })

    account = db.select(RecordID("account", "tobie")).execute()
    print(repr(account["session_timeout"]))

    sql = "RETURN d'2025-01-01T00:00:00Z' + $after"
    print(db.query(sql, {"after": Duration.parse("6h")}).first())
```

```text title="Output"
Duration(elapsed=1800000000000)
2025-01-01 06:00:00+00:00
```
