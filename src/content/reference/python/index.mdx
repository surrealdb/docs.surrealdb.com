# Python SDK

The SurrealDB SDK for Python lets you connect to SurrealDB from any Python application. It has a blocking client and an `asyncio` client, connects to a remote instance over WebSocket or HTTP, and can run an embedded database in the same process. Use it to run SurrealQL queries, read and write records, manage authentication and sessions, and receive changes as they happen with live queries.

> [!IMPORTANT]
> The SDK requires Python `3.10` or later, and is available as a [PyPI package](https://pypi.org/project/surrealdb/).

> [!NOTE]
> The latest version of the SDK is <Version sdk="python" />. It works with SurrealDB 2.x, 3.x and 4.x, and refuses other versions when it connects. The current SurrealDB release is <Version />.

If you are upgrading a project from version 2 of the SDK, read [Migrating to Python SDK 3.x](/docs/reference/python/migrating-to-3x) first. Version 3 changes what several common calls return, and version 2 cannot write datetimes to SurrealDB 4.0.

## Concepts

- [Connecting to SurrealDB](/docs/reference/python/concepts/connecting-to-surrealdb) - open a connection over WebSocket or HTTP, with timeouts and reconnection
- [Authentication](/docs/reference/python/concepts/authentication) - sign up, sign in, and keep a token fresh
- [Executing queries](/docs/reference/python/concepts/executing-queries) - send SurrealQL and read the results back
- [Data manipulation](/docs/reference/python/concepts/data-manipulation) - create, select, update, upsert, relate and delete records
- [Value types](/docs/reference/python/concepts/value-types) - how SurrealDB's types map onto Python ones
- [Live queries](/docs/reference/python/concepts/live-queries) - receive changes as they happen
- [Transactions](/docs/reference/python/concepts/transactions) - group statements so they succeed or fail together
- [Error handling](/docs/reference/python/concepts/error-handling) - what a failure looks like, and how to catch it
- [Multiple sessions](/docs/reference/python/concepts/multiple-sessions) - run isolated sessions over a single connection
- [Embedded databases](/docs/reference/python/concepts/embedded-databases) - run SurrealDB in your own process for tests and local use
- [Streaming results](/docs/reference/python/concepts/streaming) - read the records of a large query as they arrive
- [Files](/docs/reference/python/concepts/files) - store and read files in buckets
- [Import and export](/docs/reference/python/concepts/import-and-export) - back up and restore a database as SurrealQL
