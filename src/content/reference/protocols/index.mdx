# Protocols and APIs

Any language or tool capable of making HTTP requests can interact with SurrealDB, and standard Postgres and MySQL clients can connect to it as well. This is useful when an official SDK is not available for your stack, or when you need to integrate SurrealDB with infrastructure tooling, scripts, or third-party platforms.

## Ways to connect

| Protocol | What it gives you |
| --- | --- |
| [HTTP](/docs/reference/protocols/http-protocol) | Query execution over plain endpoints with JSON results, sign in and sign up endpoints, create, read, update and delete operations using RESTful conventions, and health and status checks. |
| [RPC over WebSocket](/docs/reference/protocols/rpc-protocol) | Persistent connections with real-time capabilities, including live queries and [streaming query results](/docs/reference/protocols/rpc-protocol#query_stream) that arrive while the query runs. |
| [gRPC](/docs/reference/protocols/rpc-protocol#grpc-transport) | The same RPC protocol over HTTP/2, served on the same port with `grpc://` and `grpcs://` addresses, from 3.3.0. |
| [Postgres wire protocol](/docs/reference/protocols/postgres-protocol) | Connections from `psql`, JDBC and other Postgres clients, running SurrealQL, PostgreSQL SQL or ISO GQL with tabular typed results. |
| [MySQL wire protocol](/docs/reference/protocols/mysql-protocol) | From SurrealDB 4.0, connections from the `mysql` client and MySQL drivers, running MySQL SQL, SurrealQL or another dialect. |

Client libraries for JavaScript also bring a familiar dialect to these protocols without a wire listener. The [SQL drivers](/docs/libraries/sql-drivers) send PostgreSQL or MySQL SQL through the `pgsql` and `mysql` RPC methods, and the [MongoDB driver](/docs/libraries/mongodb-driver) translates the MongoDB Node.js driver API to SurrealQL. Both connect over HTTP and WebSocket, so they also run in runtimes that cannot open a TCP socket.

- [Errors](/docs/reference/protocols/errors) - the kind, wire code, structured details and cause that every error carries, in the same shape across every protocol and SDK.

## Official SDKs

If you prefer a richer client experience, the official SDKs are language-specific clients for [JavaScript](/docs/languages/javascript), [Python](/docs/languages/python), [Rust](/docs/languages/rust), [Go](/docs/languages/golang), [Java](/docs/languages/java), [.NET](/docs/languages/dotnet) and [PHP](/docs/languages/php).
