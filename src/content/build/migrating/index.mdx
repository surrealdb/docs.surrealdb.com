# Migrating

This section describes how to move data into SurrealDB: from other databases, from older SurrealDB versions, and from files or streams (for example CSV, JSON Lines, or Kafka). Use the subsections for the path that matches your source.

## Moving between SurrealDB Cloud instances

A Free instance moves to a paid instance type in place, from the **Compute** tab of its settings, with no migration. See [Scaling](/docs/manage/instances/scaling#scaling-a-start-instance).

Moving from Start to Scale, or to another region, needs a new instance. Deploy it, then [restore a backup](/docs/manage/instances/backups) or [import an export](/docs/manage/instances/import-and-export) into it.
