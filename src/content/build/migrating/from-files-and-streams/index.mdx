# Migrating from files and streams to SurrealDB

This section details how to map data, queries and concepts you may know from other databases and datatypes into SurrealDB.

The sources in this section of the documentation can be automatically imported to SurrealDB using the [Surreal Sync](https://github.com/surrealdb/surreal-sync/) tool. In addition, [CSV data](/docs/build/migrating/from-files-and-streams/csv) can be automatically imported into SurrealDB Studio using its own [built-in functionality](/docs/explore/studio).

For a source that is not yet supported, export the data as [JSON Lines](/docs/build/migrating/from-files-and-streams/json-lines) and import it with Surreal Sync, or write it out as SurrealQL `INSERT` statements and load the file with [`surreal db import`](/docs/reference/cli/db/commands/import), which takes a SurrealQL file. Alternatively, you can use [one of the many available SDKs](/docs/languages) to access your existing database and transfer its content directly to a SurrealDB instance.
