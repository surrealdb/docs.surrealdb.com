# Libraries

Libraries are packages that add a higher-level interface to SurrealDB, such as a schema, models, a typed query builder or SQL dialect support. The Surqlize libraries use a SurrealDB SDK to connect to the database and to run queries, so the SDK's connection and authentication options apply to them. The SQL drivers connect to the database themselves.
