# SurrealQL in CodeMirror

The `@surrealdb/codemirror` package adds SurrealQL to a [CodeMirror 6](https://codemirror.net) editor, for pages that let people write queries.

The package provides:

- SurrealQL highlighting, including embedded JavaScript in `function() { ... }` bodies.
- Folding for blocks, objects and arrays.
- Automatic indentation and comment toggling.
- A linter that reports syntax which a given SurrealDB version does not support.

## Before you start

- A project that already uses CodeMirror 6, with `@codemirror/state` and `@codemirror/view` installed.
- A package manager such as npm, pnpm or yarn.

## Install

```bash
npm install @surrealdb/codemirror
```

The package ships ES module and CommonJS builds and its own TypeScript types.

## Add SurrealQL to an editor

Pass the `surrealql()` extension to the editor state:

```ts
import { EditorState } from "@codemirror/state";
import { EditorView } from "@codemirror/view";
import { surrealql } from "@surrealdb/codemirror";

const state = EditorState.create({
    doc: "SELECT * FROM person WHERE age > 18;",
    extensions: [surrealql()],
});

new EditorView({
    parent: document.getElementById("editor")!,
    state,
});
```

The `surrealql()` extension is a standard CodeMirror `LanguageSupport`, so it combines with other CodeMirror extensions such as themes, key maps and line numbers.

## Lint for a SurrealDB version

`surrealqlVersionLinter()` takes the SurrealDB version your users run, and reports syntax in the document that this version does not support. Add it beside `surrealql()`:

```ts
import { surrealql, surrealqlVersionLinter } from "@surrealdb/codemirror";

const extensions = [surrealql(), surrealqlVersionLinter("2.0.0")];
```

The linter reports through `@codemirror/lint`, so diagnostics appear with the lint styling you have configured.

## Edit part of a statement

Pass a scope to `surrealql()` when the editor holds a fragment instead of a full script. The scope sets what the editor expects to parse:

| Scope | Expected content |
| --- | --- |
| `permission` | The contents of a `PERMISSIONS` clause, such as `FOR select WHERE published = true`. |
| `index` | The clauses of an index definition, such as `FIELDS name UNIQUE`. |

```ts
const extensions = [surrealql("permission")];
```

## Use the grammar directly

`@surrealdb/codemirror` builds on `@surrealdb/lezer`, which holds the [Lezer](https://lezer.codemirror.net) grammar. Use the CodeMirror package for an editor. Install the Lezer package on its own to parse SurrealQL into a syntax tree outside an editor.
