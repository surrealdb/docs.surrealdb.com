# Install the nightly

Nightly builds include the latest features and bug fixes. They are available for macOS, Linux and Windows through the install scripts and `surreal upgrade`, or through Docker using the `nightly` tag. A nightly is an unreleased build, so use it to try changes early rather than in production.

## Installing the nightly on macOS and Linux

The install script installs `surreal` and the latest nightly database, and pins it as the default. Re-run the command to move to the newest build.

```bash
curl --proto '=https' --tlsv1.2 -sSf https://download.surrealdb.com/cli/launcher/install.sh | sh -s -- --nightly
```

## Installing the nightly on Windows

```powershell
& ([scriptblock]::Create((irm https://download.surrealdb.com/cli/launcher/install.ps1))) -Nightly
```

## Upgrading an installed database to the nightly

With `surreal` already installed, upgrade the database component to the latest nightly. The `--nightly` flag is shorthand for `db@nightly`.

```bash
surreal upgrade --nightly
```

```bash
surreal upgrade db@nightly
```

To run one command against the nightly without changing the default, use `+nightly`, as in `surreal +nightly db start`. See [Managing components](/docs/explore/cli/components#run-another-version-once).

## Using the nightly with Docker

To use the nightly with Docker, use the `nightly` tag. When running the following command, Docker pulls the latest nightly from Docker Hub.

```bash
docker run --rm --pull always -p 8000:8000 surrealdb/surrealdb:nightly start
```
