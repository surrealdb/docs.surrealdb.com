# Install on Windows

The PowerShell install script installs `surreal`, the SurrealDB command-line tool, and the database with it. `surreal` installs, updates and runs the database as a component, so `surreal db start` works from then on without a network connection. [Chocolatey](https://chocolatey.org/) and [Scoop](https://scoop.sh/) are also available.

## Installing with the PowerShell install script

The [install script](https://download.surrealdb.com/cli/launcher/install.ps1) downloads `surreal` and the database, checks each download against its published SHA-256, and installs `surreal.exe` into `C:\Program Files\SurrealDB` from an elevated shell, or `%LOCALAPPDATA%\SurrealDB` otherwise. It adds that folder to your user `PATH`.

```powershell
irm https://download.surrealdb.com/cli/launcher/install.ps1 | iex
```

`irm | iex` cannot pass options. To pass them, run the script as a script block. The database is installed by default; `-NoDb` installs `surreal` alone, and the database installs on first use instead.

```powershell
& ([scriptblock]::Create((irm https://download.surrealdb.com/cli/launcher/install.ps1))) -NoDb
```

The `SURREAL_CLI_INSTALL_DB` environment variable (`1` or `0`) sets the same switch for callers that cannot pass options. See [Install the SurrealDB CLI](/docs/explore/cli/install) for every option, including installing the Cloud component alongside.

### Installing a specific version of the database

Use `-Version` to install and pin a database release.

```powershell
& ([scriptblock]::Create((irm https://download.surrealdb.com/cli/launcher/install.ps1))) -Version <version>
```

### Updating

Once installed, `surreal` upgrades itself and every installed component. The database stays on its current major line.

```powershell
surreal upgrade
```

To move the database to another release, name it: `surreal upgrade db@<version>`. See [Managing components](/docs/explore/cli/components).

## Confirming the installation

Run the following command to check that the database component runs.

```powershell
surreal db version
```

```text title="Sample output"
3.3.4 for windows on x86_64
```

To list `surreal` and every component with the version that runs, use `surreal version`.

## Installing SurrealDB using Chocolatey

If you use the [Chocolatey](https://chocolatey.org/) package manager, then you can quickly install SurrealDB with one command. This installs the database as a single `surreal` executable.

```powershell
choco install surreal
```

### Updating SurrealDB

To ensure that you are using the latest stable version (<Version />), update SurrealDB using the following command.

```powershell
choco update surreal
```

## Installing SurrealDB using Scoop

If you use the [Scoop](https://scoop.sh/) package manager, then you can quickly install SurrealDB with one command. This installs the database as a single `surreal` executable.

```powershell
scoop install surrealdb
```

### Updating SurrealDB

To ensure that you are using the latest stable version (<Version />), update SurrealDB using the following command.

```powershell
scoop update surrealdb
```

## Troubleshooting

### DLLs not installed

**Attempting to open the executable at the install location throws errors that the following DLLs are not installed**

If you encounter an error saying that the following DLLs are not installed:
* VCRUNTIME140.dll
* MSVCP140.dll
* VCRUNTIME140_1.dll

Then you may need to install the [Microsoft Visual C++ Redistributable for Visual Studio](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist?view=msvc-170#latest-microsoft-visual-c-redistributable-version).
