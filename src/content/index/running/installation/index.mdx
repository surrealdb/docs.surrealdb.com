# Installation

If you are not ready to install anything yet, start with the [SurrealDB Studio Sandbox](/docs/running/sandbox) or [SurrealDB Cloud](/docs/running/cloud) as described in the [Running overview](/docs/running/overview).

One of the most popular ways to get started with SurrealDB is to install and run it as a standalone database service, allowing any number of clients to connect to it and interact with the data.

You install one command, `surreal`. It installs the database as a component, keeps it current, and runs it with `surreal db <command>`. The same command installs and runs the other [components](/docs/explore/cli/components), such as `cloud` for SurrealDB Cloud. This section covers installing it on your local machine for development or as a production database.

The current stable version of SurrealDB is <a href='/releases'> <Version /></a>.

## Installation steps

The install script is the same on every platform: it installs `surreal` and, by default, the database. The pages below give the steps for each operating system, including the package managers that install the database on its own. [Install the SurrealDB CLI](/docs/explore/cli/install) lists every option of the install script.

## SurrealDB Cloud

Running and maintaining your own database can be a time consuming task. That's why we offer [SurrealDB Cloud](/docs/manage/instances), a fully managed database service that allows you to focus on building your applications without worrying about the underlying infrastructure.

## Beta and nightly builds

- [Beta](/docs/running/installation/beta) - install the SurrealDB 4.0 beta before its stable release
- [Nightly](/docs/running/installation/nightly) - install an unreleased build to try changes early
