SurrealDB stores relational, document, graph, time-series, vector and full-text data in one engine, queried through SurrealQL and reachable from ten official SDKs. It runs embedded in your application, as a single node, or as a distributed cluster, and SurrealDB Cloud runs it for you, on dedicated instances or serverless on [SurrealDB Earth](/docs/operate/instances/earth).

## Your first query

SurrealQL is SQL-shaped, so most of it reads as you would expect. What it adds is the ability to relate records directly and traverse those relations in the same statement, without a join table or a second database. Edit and run this:

<SurrealistMini query="-- Records are addressed by table and id
CREATE person:alice SET name = 'Alice';
CREATE company:acme SET name = 'Acme';
-- RELATE creates a graph edge, which can carry its own fields
RELATE person:alice->works_at->company:acme SET since = d'2024-01-15';
-- Traverse the edge from the record, in the projection
SELECT name, ->works_at->company.name AS employers FROM person;
" />

The [querying guide](/docs/learn/querying) covers the language properly, and [data models](/docs/learn/data-models) covers what else the engine stores.

## Connect from your language

Choose a language to see how a first connection looks, then continue in that language's quickstart, which goes on to insert and query data.

<Tabs syncKey="language">
<TabItem label="Rust">
```sh
cargo add surrealdb --features kv-mem,protocol-ws
cargo add tokio --features macros,rt-multi-thread
```

```rust
use surrealdb::engine::remote::ws::Ws;
use surrealdb::opt::auth::Root;
use surrealdb::Surreal;

#[tokio::main]
async fn main() -> surrealdb::Result<()> {
    let db = Surreal::new::<Ws>("127.0.0.1:8000").await?;

    db.signin(Root {
        username: "root".to_string(),
        password: "secret".to_string(),
    })
    .await?;

    db.use_ns("main").use_db("main").await?;

    Ok(())
}
```

The [Rust quickstart](/docs/languages/rust) continues with inserting and querying data, and the [Rust SDK reference](/docs/reference/rust) covers every method.
</TabItem>

```go
ctx := context.Background()

db, err := surrealdb.FromEndpointURLString(ctx, "ws://localhost:8000")
if err != nil {
	log.Fatal(err)
}
defer db.Close(ctx)

_, err = db.SignIn(ctx, surrealdb.Auth{
	Username: "root",
	Password: "secret",
})
if err != nil {
	log.Fatal(err)
}

if err := db.Use(ctx, "main", "main"); err != nil {
	log.Fatal(err)
}
```

The [Go quickstart](/docs/languages/golang) continues with inserting and querying data, and the [installation guide](/docs/reference/golang/installation) covers versions.

<TabItem label="Kotlin">
```kotlin
import com.surrealdb.kotlin.SurrealClient
import com.surrealdb.kotlin.SurrealClientConfig
import kotlinx.coroutines.runBlocking
import kotlinx.serialization.json.buildJsonObject
import kotlinx.serialization.json.put

fun main() = runBlocking {
    val client = SurrealClient(SurrealClientConfig(url = "ws://localhost:8000"))

    client.signin(buildJsonObject {
        put("user", "root")
        put("pass", "secret")
    })
    client.use("surrealdb", "docs")

    client.close()
}
```

Add the SDK to your build as described in the [installation guide](/docs/reference/kotlin/installation). The [Kotlin quickstart](/docs/languages/kotlin) continues with inserting and querying data.
