# Operate

This section contains operational documentation for SurrealDB Cloud, including serverless [SurrealDB Earth](/docs/operate/instances/earth) instances, and for self-hosted deployments. These pages assume a database that already exists and concentrate on keeping it running, observable and up to date.

## Enterprise

[SurrealDB Enterprise](/docs/operate/enterprise) adds the controls a regulated deployment needs, including single sign-on, centralised member management, and custom roles. Self-hosted clusters can also run [Enterprise Edition](/docs/operate/enterprise/product/database-enterprise) for FIPS-validated cryptography, distributed live queries, and audit logging.

## Related sections

Manage Cloud from the command line with [`surreal cloud`](/docs/reference/cli/guides/cloud). The full command surface for `surreal` and `surqlfmt` is in the [CLI reference](/docs/reference/cli). The pages here cover what to run and when; the reference covers every flag.
