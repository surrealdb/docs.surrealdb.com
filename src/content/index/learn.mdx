## Where to start

Reading order depends on what you are building. For an application backend, [querying](/docs/learn/querying) then [schema management](/docs/learn/schema-management) covers most of what you need. For a data model that spans relations and graph edges, start at [data models](/docs/learn/data-models). Anything that will hold user data wants [security](/docs/learn/security) before it ships. If you have not used a database before, [database basics](/docs/learn/database-basics) explains the ideas that the other sections build on.
