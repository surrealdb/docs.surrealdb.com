# Integrate

This section covers connecting SurrealDB Agent Memory to the code and tools around it, and moving to it from another memory layer. [Learn](/docs/agent-memory/learn) explains how the memory itself works.

Every integration talks to the same context, through the same REST API, so you can start with one and add others later. An SDK suits an application that you write yourself. The MCP server gives a coding assistant or any other MCP-capable agent a memory without code. A framework or AI SDK integration fits an agent that you have already built on that library, and a voice integration keeps a memory across calls.
