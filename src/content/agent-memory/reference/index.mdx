# Reference

This section holds the complete technical reference for SurrealDB Agent Memory: the APIs, the configuration options and the command-line tools. It is organised for lookup. [Learn](/docs/agent-memory/learn) explains how the pieces work, and [Integrate](/docs/agent-memory/integrate) covers connecting to them.

The REST API is the contract that every other surface follows. The SDKs, the CLI and the MCP tools each call it, so a field that one of them does not expose can still be set over REST. The SDK references cover Python, JavaScript, Kotlin and Swift, and the other client libraries have a page of their own under [Integrate](/docs/agent-memory/integrations).
