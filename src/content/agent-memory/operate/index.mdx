# Operate

SurrealDB Agent Memory runs as contexts on SurrealDB Cloud, or as a deployment of your own on the Enterprise plan. These pages cover where a context runs, what you can configure on it, and how to watch the agents that use it.

## Choosing where to run

| | Contexts on SurrealDB Cloud | Dedicated cluster | Enterprise deployment |
| --- | --- | --- | --- |
| Compute | A shared pool | Nodes that only your organisation uses | A single-tenant deployment |
| Language models | Google, OpenAI, Anthropic, Cerebras and OpenRouter models, chosen per context | Your own model keys or a model gateway | The same, plus your own model through an OpenAI-compatible endpoint |
| Plan | Sandbox, Lite, Standard and Plus | Part of the Enterprise offering | Enterprise |
