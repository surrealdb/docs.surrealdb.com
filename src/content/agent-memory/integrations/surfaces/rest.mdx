# REST API

SurrealDB Agent Memory exposes a REST API over HTTP from the **api** role. Every SDK and harness adapter maps to these endpoints, so you can integrate from any language that can make HTTP requests.

## URL structure

The api server (default port **9090**, set with `SPECTRON_BIND_ADDRESS`) serves:

| Path | Purpose |
| --- | --- |
| `/api/v1/{context_id}/...` | End-user operations: facts, documents, query, chat, sessions, traces |
| `/api/v1/health` | Liveness |
| `/mcp` | MCP server (Streamable HTTP); same Bearer auth |

The management API (`/api/v1/contexts/...`, for Context lifecycle and key provisioning with a management key) runs as a separate server on its own listener, set with `SPECTRON_MANAGEMENT_BIND_ADDRESS`.

The `{context_id}` segment is the identifier you assigned at bootstrap (for example `dev`), not an opaque UUID unless you chose one.

## Authentication

```http
Authorization: Bearer <api_key>
```

Do not send a raw secret without the `Bearer` prefix. Management and end-user keys both use the same header; the server infers capabilities from the key material.

Optional on writes:

```http
Idempotency-Key: <stable-id>
```

## The four verbs

| Verb | Endpoint | When to use |
| --- | --- | --- |
| Remember | `POST /api/v1/{ctx}/facts`, `POST .../facts/batch` | Conversations, single facts, harness batch capture |
| Upload | `POST /api/v1/{ctx}/documents` | PDFs, manuals, code, media |
| Recall | `POST /api/v1/{ctx}/query` | Ranked hits over the unified substrate |
| Chat | `POST /api/v1/{ctx}/chat` | Let SurrealDB Agent Memory run recall + synthesis |

For formatted prompt text without raw hit lists, use `POST /api/v1/{ctx}/context`.

## Example: remember and recall

```bash
export AGENT_MEMORY_ENDPOINT=http://localhost:9090
export AGENT_MEMORY_API_KEY=<context-key>
export AGENT_MEMORY_CONTEXT=dev

curl -sS "$AGENT_MEMORY_ENDPOINT/api/v1/$AGENT_MEMORY_CONTEXT/facts" \
  -H "Authorization: Bearer $AGENT_MEMORY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"text":"Alice was promoted to CTO.","infer":"full","scopes":["org/acme/user/alice"]}'

curl -sS "$AGENT_MEMORY_ENDPOINT/api/v1/$AGENT_MEMORY_CONTEXT/query" \
  -H "Authorization: Bearer $AGENT_MEMORY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"query":"What is Alice'\''s role?","k":10,"lens":["org/acme/user/alice"]}'
```

The [`agent-memory`](/docs/agent-memory/reference/cli) CLI wraps the same paths (`agent-memory remember`, `agent-memory recall`, `agent-memory chat`).
