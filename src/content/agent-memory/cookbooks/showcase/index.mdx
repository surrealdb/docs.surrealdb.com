# Showcase

Each demo in this section is a finished piece built on SurrealDB Agent Memory: a corpus ingested into a Context, and pages drawn from what the memory holds. Every demo opens with the result, embedded so you can use it on the page, and follows it with how it was built, so you can adapt the same steps to your own data.
