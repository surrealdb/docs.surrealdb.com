## surreal

Start, query, import and export SurrealDB from the command line

Usage: surreal [OPTIONS] <COMMAND>

Commands:
  start     Start the database server
  import    Import a SurrealQL script into an existing database
  export    Export an existing database as a SurrealQL script
  version   Output the command-line tool and remote server version information
  sql       Start an SQL REPL in your terminal with pipe support
  mcp       Start the MCP server over stdio for AI assistant integration
  is-ready  Check if the SurrealDB server is ready to accept connections [alias: isready]
  validate  Validate SurrealQL query files
  fix       Fix database storage issues
  help      Print this message or the help of the given subcommand(s)

Options:
  -v, --version  Print version
  -j, --json     Emit machine-readable JSON on stdout
  -h, --help     Print help

Logging:

           as 'api.surrealdb.com' or 'a.b.surrealdb.com', but not 'surrealdb.com' itself) on any
           port
           - '*.surrealdb.com:443' -> Match outbound connections to any subdomain of surrealdb.com
           on port 443
           - '10.0.0.0/8' or 'fd00::/8' -> Match outbound connections to any host in these networks
          A wildcard is only allowed as the whole leftmost label and must be followed by a domain of
          at least two labels; it never matches an IP address.
          
          [env: SURREAL_CAPS_DENY_NET]
